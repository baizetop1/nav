# 博客工作台

入口：首页“博客工作台”、管理导航页“前往博客工作台”，或直接访问 `#/blog`。全局命令面板也可以搜索“博客”。现有 Inbox 转草稿/发表入口保留。

## 写作与管理

1. 点击“新建文章”，直接填写标题和正文，无须先创建 Inbox 记录或输入 Token。
2. 每篇文章分别自动保存到当前浏览器；刷新后继续最近编辑的文章。保存中的状态、容量不足和跨标签页冲突会明确显示。
3. “文章设置”可修改分类、形式、标签和新文章的 Slug。“源码”可以编辑完整 Markdown；既有 Front Matter 未编辑字段、注释和未知嵌套配置会保留。
4. 支持写作、预览、对照、源码四种视图，工具栏可插入标题、粗体、代码块、链接和 HTTPS 图片地址。可选择、拖入或在正文粘贴本地图片；先预览，勾选公开上传确认后才提交到博客仓库。
5. 可按标题/文件名搜索和筛选本地草稿、仓库草稿、已发布文章。远端列表首次使用文件名展示，打开后读取正文中的真实标题。
6. 可导入或导出 Markdown。“移除本地编辑副本”只影响本机，不删除 GitHub 文章。

预览只渲染支持的 Markdown 子集，不执行 HTML、Liquid 或脚本；最终排版以博客主题为准。

## 连接和提交

“连接博客仓库”使用 `siteConfig.blogRepository`，目前为 `baizetop1/baizetop1.github.io` 的 `master` 分支。公开仓库列表可不填 Token；写入需运行时 PAT 的 Contents 读写权限。Token 只留在当前工作台内存，退出/刷新后重新填写，不进入本地草稿、导出文件或备份。

- **保存为仓库草稿**：新建或更新 `_drafts/<slug>.md`。
- **预览并发表**：生成 `_posts/YYYY-MM-DD-<slug>.md`；如果来自远端草稿，同一提交内移除原草稿。
- **预览文章更新**：更新原 `_posts` 路径，保留日期、Slug 和永久链接；没有 Slug 的旧中文文件名文章也可以更新。

每次先只读准备预览，勾选确认后才提交。编辑正文或元信息会使之前的提交预览失效。提交不等于上线：工作台根据对应提交的 GitHub Pages 部署记录显示等待、运行、成功或失败；不会把其他 CI 成功当作部署成功。状态检查有时间上限，可手动重试。

**公开仓库的草稿文件同样公开可读。** 本机草稿才是本地内容；不要把私密资料、密码、Token 等提交到公开博客。服务不会自动上传或自动发布。

## 冲突与数据安全

- 打开远端文章时保留文件 SHA 和正文基线。预览、提交前重新检查该文件；无关文件的改动不会阻断提交，目标文章变化则停止覆盖。
- 冲突后可“读取远端并比较”：按原文、本机、远端三方比较改动块，自动合并不同位置的修改；同一处冲突逐块选择。本机再有新编辑时旧选择失效；确认合并只自动保存到本机，发布仍会检查远端是否再次改变。大量改动会使用较大的比较块，避免页面卡顿。
- 本地每篇稿件以独立 key、revision 和 Web Lock 保存。另一标签页写入、删除、损坏记录时，不会用旧文本静默覆盖新数据；可另存副本或导出。
- 浏览器存储失败时内容保留在当前页面，避免关闭或刷新，先导出 Markdown。安全自动保存需要 HTTPS/localhost 和支持 Web Locks 的浏览器。
- 当前每篇 Markdown 上限 256 KiB。本地草稿按博客仓库和分支隔离，已纳入导航完整备份及加密云备份；首页“待同步”也可批量备份/恢复工作草稿。日常 Inbox 加密合并同步不包含这些工作草稿。恢复保留原文、远端基线和提交记录，同编号的不同内容另存副本。
- PWA 首次在线完成缓存后可以离线打开工作台、写作和保存；读取仓库、发布、部署查询及外部图片需要网络。

## 验证

- `npm run test:blog-enhancements`：无损分块合并、插入/删除与大改动边界，以及模拟图片上传权限、格式、冲突和大小检查。

- `npm run test:blog-workspace`：本地保存、容量、损坏记录与并发保护。
- `npm run test:blog-workbench`：Markdown 保真、旧文章兼容、GitHub 提交计划与冲突保护。
- `npm run check:blog-workbench`：桌面/手机浏览器回归，GitHub 读写全部拦截并模拟。
- `npm run check:blog-autosave`：双标签页自动保存、存储故障和冲突回归；需 Vite 开发服务，默认端口 5192，可用 `BAIZE_BLOG_DEV_URL` 调整。
- `npm run verify:app`：生产构建及所有非游戏自测。

浏览器测试需要本机 Playwright、Edge 和生产预览服务，默认 `http://127.0.0.1:5189/nav/`；可通过 `BAIZE_PLAYWRIGHT_PATH` 和 `BAIZE_APP_URL` 调整。

## 图片上传边界

支持 PNG、JPEG、GIF、WebP，按文件签名识别，单图最多 5 MiB，拒绝 SVG/HTML。预览文件仅保存在内存，不写入 LocalStorage 或备份；离开前完成上传或取消。上传创建 `assets/images/posts/<slug>/<随机编号>.<扩展名>`，从不覆盖已有图片。

图片单独产生一次仓库提交，文章引用插入后仍需等待本地保存并另行发布。站点图片地址需等待博客部署；当前编辑预览可使用固定到图片提交的原始文件地址。取消文章不会自动删除已上传图片。上传超时或响应不完整时先查看仓库再重试，避免重复文件。上传前请移除图片中的隐私信息及 EXIF；本工具不自动清理元数据。
