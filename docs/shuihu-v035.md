# 0.35.0 手机按屏翻页

## 界面

- 手机（宽度不超过 900px）所有功能页面按可用屏幕高度排版。内容超过一屏时显示上一页、下一页和页码输入；顶部的功能选择不随正文翻页。
- 营建设施、好汉名册与档案、经验养成、兵种、品阶、招贤、材料副本、行囊、打造、差事、地图、存档等均沿用同一分页方式。长详情展开后重新计算页数，完整文字与按钮保留。
- 常规弹窗、十连结果、批量培养、生产收取、工坊、传功、扫荡、存档比较都采用紧凑正文及固定操作区域。出征准备和战斗结算保留 0.34.1 的分栏、奖励列表与固定确认按钮。
- 日志展开后也可翻页。阅读旧页时暂停跟随，点击回到最新返回末页。
- 横竖屏及窗口大小变化时重新排版，并保留未提交的输入。战斗刷新不会在按住按钮时重新安排正文节点。
- 桌面沿用原有布局。文本框内编辑、系统下拉菜单和文件选择器按系统行为处理。

## 兼容与发布

不改存档结构、抽取概率、资源消耗或奖励；不需要新增数据库迁移，也无需仅为本版本部署 Worker。网页沿用现有发布流程。Android versionCode 36 / versionName 0.35.0，使用已有签名覆盖安装以保留 App 数据。

APK：`artifacts/android/baize-shuihu-0.35.0.apk`。构建与签名说明见 `android/README.md`。不要卸载旧版本来升级。

## 验证

启动开发服务器后运行：

```powershell
$env:SHUIHU_PLAYWRIGHT_PATH='C:/Users/dissbz/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright'
npm run check:shuihu-screen-pages
npm run test:all
npm run build
```

Playwright 可通过环境变量指定安装路径；默认使用可解析的 `playwright` 模块和本机 Edge。`SHUIHU_GAME_URL` 可覆盖默认的本地开发地址。

浏览器脚本覆盖 320×568、360×640、390×844、844×390 的 60 个页面状态：检查正文完整、控件不截断、无页面纵向溢出；同时用实际游戏运行流程验证页码、配置保存、输入保留、十连仅扣一次、导出存档、实时战斗暂停和日志翻页。结果写入 `artifacts/screen-pages/`。

另外检查了 11 类弹窗、桌面与手机主线寻迹接续，以及 APK 内置 HTTPS 路径的离线开局、存档导出导入和重载。尚未连接 Android 真机；不同厂商 WebView、系统文件选择器和系统返回键仍需实际安装体验。
