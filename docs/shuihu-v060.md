# 0.60.0：寨门与山路

本轮先完成一段可游玩的场景体验：回寨 → 与寨中人物交谈 → 查看寨外山路 → 整队清剿 → 战后回寨。没有替换原有主线，也没有一次性给所有地点加图。

## 体验入口

刷新游戏，点击寨子总览上的场景图“入寨看看”，或从全部寨务进入“寨门小叙”。

- 寨门可以问山路、问寨务，直接去林口或处理营建、伤兵。
- 林口可以查看车辙，再打开原有山林清剿的出征准备；也能直接回寨。
- 山林清剿结算增加“回寨看看”，回寨对白反映最近一次胜利、撤退、失利及兵损。
- 看图、对话、走到林口、查看痕迹均不扣资源。确认出征才按原规则扣体力和粮草；取消准备不扣除。

场景浏览不是大地图旅行，不改变主线地点，也不绕过任何战斗条件。林口按钮仍调用现有 `campRaid: woods`。战斗、掉落、成长、募兵、阵亡、招募概率没有改动。交谈无重复领取奖励的入口。

## 场景与人物回应

新增三个本地 WebP 素材，保留原始 2172×724 分辨率，总计约 1.03 MiB：

- `public/game/art/scenes/camp-gate-v1.webp`：初立的寨门。
- `public/game/art/scenes/camp-repaired-v1.webp`：修整后的同一处寨门。
- `public/game/art/scenes/woodland-path-v1.webp`：倒车旁的林口山路。

聚义厅至少 2 级且伐木场已建成时，自动显示修整后的寨门。画面没有另设需要付费的装修操作。根据游戏时钟的北京时间，显示白天、傍晚或夜间色调；这是同一图片的轻微显示滤镜，不是实时天气系统。

优先由已入寨且未外派的白胜、杜迁或宋万回应；无人符合时由守门乡勇接话。已有角色头像复用现有素材。林口显示现场痕迹，不把未随队的人放到场景中。对话读取营建设施、伤兵和最近战果，询问选择只在本次页面中保留。

## 手机布局

寨门和林口使用独立场景页；总览只增加一条可以点击的横幅。小屏横幅与场景图限高，图片不会继续把页面撑长；想看细节时可以打开全景，再关闭回到原位置。新增对话、查看痕迹和出发按钮在 320×568 的默认收起日志布局下能同屏使用。

检查尺寸为 320×568、390×844、1280×900。极短横屏或用户放大字体时仍可使用原有分页，不裁掉正文或按钮。没有把整个游戏改成图形地图，也没有给所有十二卷配齐插图。

## 审查建议

1. 点击寨子横幅，问问山路和寨务，查看对白是否比功能说明更像人物在接话。
2. 点场景图打开全景，然后收起；确认手机主要按钮仍好点。
3. 去林口查看车辙，打开出征准备后先取消，核对资源没有扣除。
4. 实际完成一次山林清剿，领取奖励后点“回寨看看”，核对对白和战果一致。
5. 有伤兵时再回寨，查看医治入口；新寨与已营建的寨子显示不同画面。

## 存档、测试与发布

本轮只读取现有存档字段，不增加存档结构、云端能力或数据库表。刷新或重新读档后，场景会依据已有营建和最近战果恢复；对话页的临时选择会重置。若云端已部署 0.59 的 Worker，这一轮场景功能本身不要求再更新 Worker；若 0.59 的任务、路线、挑战尚未发布，仍需先部署支持它们的 Worker。

新增 `test:shuihu-scenes` 检查浏览只读、人物在场条件、营建变体、真实出征费用、胜败/撤退回应、导出导入和本地图片。`check:shuihu-scenes` 用隔离存档跑实际浏览器战斗并检查结算返回与刷新，未读取或覆盖玩家的真实存档。

```bash
npm run test:game
npm run check:shuihu-scenes
npm run build
```

浏览器脚本需要 Playwright 和 Edge，可用 `SHUIHU_PLAYWRIGHT_PATH` 指向已安装的 Playwright。截图位于 `artifacts/scenes/`。素材使用内置 image_gen 工具生成；完整提示词见 `public/game/art/scenes/README.md`。

验证结果：92 项游戏自检全部通过；三种尺寸的浏览器完整流程通过；生产构建通过（导航站原有大于 500 kB 的主包提示仍在）。

本轮没有推送 GitHub、部署线上或构建 APK。
