# 白泽水浒 · 聚焦页面（0.2.2）

本次仅整理信息和操作入口，不改剧情、地图、招募概率、战斗规则或存档格式。

## 一页一种主要用途

| 页面 | 默认显示 | 次要内容的位置 |
| --- | --- | --- |
| 江湖 | 当前地点、可走路线、当地剧情和寻访 | 招贤/打造是独立入口，不再嵌入整个功能表单 |
| 好汉 | 已入寨成员、阵容和养成 | 相识/线索人物与技能背景折叠；未闻人物合并计数 |
| 招贤 | 普通招贤、一个选定的专属邀请对象 | 下拉切换人物，规则和保底按需展开；结果仍用弹窗显示 |
| 行囊 | 当前持有物品及使用入口 | 装备、材料合成、城中采买分别折叠 |
| 铁匠铺 | 装备穿戴和强化 | 从江湖铁匠铺或行囊装备区进入；打造目录和规则折叠 |
| 差事 | 今日差事和已开启的待办主线 | 已领酬劳、后续主线、进行中的往事按需展开 |
| 梁山志 | 当前篇章目标和最近 15 条记事 | 山寨概况、眼下线索、其他篇章、较早日志按需展开 |
| 存档 | 导入、导出、备份恢复 | 「另开新卷」危险操作默认折叠 |

原来每页重复的右侧概况集中到「梁山志 → 山寨概况与眼下线索」。卷终条件留在梁山志当前篇章里。页面顶部只显示当前功能需要的资源，不再列出整套全局指标。

铁匠铺作为行囊/江湖的子功能，不增加一整套全局导航。远离铁匠铺时会提示先到店，不绕过地点要求。

## 交互边界

- 上一页面的操作提示不带到新页面；招募结果只在弹窗显示，不重复插入全局提示栏。
- 错误、存储失败及多标签冲突仍明确显示，不因精简而隐藏。存档入口始终可达。
- 当前页已展开的分组，在操作后或时钟刷新时保持展开；切换到新页面按默认折叠状态显示。
- 专属招贤的下拉选择只影响界面，不扣道具、不写入存档，也不会自动招募。使用最后一张令后仍保留当前邀请对象。
- 原存档 version 2 继续可用；未解锁内容、旧日志及人物资料没有被删除。

## 检查

- `npm run test:shuihu-focus`：页面隔离、概况搬迁、招贤单对象显示、折叠区域、地点限制、消息转义和存档警告。
- `npm run verify`：生产构建及全部 27 组自检。
- 浏览器回归：两卷剧情、导入导出/坏档/存储不足/跨标签、普通和专属招募弹窗、阵容保存、装备穿戴和强化、折叠状态保持。
- 桌面及 320/390/768px 检查无横向溢出，手机尺寸可操作。

旧手机 `structuredClone` 兼容问题仍按先前要求另行处理。这些尺寸检查使用现代浏览器内核，不代表旧内核已修复。未自动提交或推送 GitHub。

## 0.2.3 · 小图标

- 七个导航项以小图标替换原数字序号，仍保留完整中文标签；当前项的图标与文字一起高亮。
- 当前页面标题、主要操作按钮、相关资源数值增加同一套细线 SVG；不增加新面板，也不改变游戏规则。
- 图标本地内嵌，无外部图片、字体或图标库请求。图标对读屏隐藏，不单独获取焦点；按钮的文字、禁用状态和键盘操作保持。
- 常规图标为 18px，手机导航为 16px。点击图标区域与点击文字执行相同操作，不增加独立的小点击目标。
- 新增 `npm run test:shuihu-icons`，全部自检增至 28 组。桌面及 320/390/768px 检查显示、换页、按钮点击和招募结果弹窗。
