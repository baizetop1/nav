# 白泽水浒 0.47.1：文案与浅色配色调整

本轮依据玩家对文案和配色的反馈，修改寨子指引、人物、行囊、主线与出征的常见界面文字。没有重写全部剧情。

## 界面

- 暖白底色、淡灰分隔线；按钮改为浅绿底与灰绿色文字，领取酬劳使用浅金色。
- 常用寨务入口合并在一个区域内，去除每个按钮重复的边框。
- 人物属性使用浅灰底，气血为暗红，其他数值为灰绿；经验条统一为浅绿。
- 保留夜间切换和原有手机分页。
