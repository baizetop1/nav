# 白泽水浒 0.52.0：梁山去路，十二卷主线完结

本轮开放第八至十二卷，接通第一至十二卷完整主线。终章有守泊护乡、渡海安家、护民归乡三个实际可完成的结局，各有三段战斗任务和人物后记。逐卷内容与规则见 [主线实施记录](shuihu-mainline-plan.md)。

## 从哪里继续

完成第七卷《破连环马》后，点击寨子首页“继续主线”，前往曾市外营。也可从泊东营地进入。此后依次完成曾头疑云、大名救援、百川归泊、两道诏书和梁山去路；已有七卷结卷档可直接接续。

新增 27 处地图、33 段故事、31 种敌人、20 个战役定义。第八至十一卷有 11 场必经战斗，第十二卷三条路线各 3 场；因此单个正式存档走完新增五卷为 **14 场战斗**，三条终章合计才是 20 个定义。战斗中的增援波次属于同一次出征，不额外扣体力和粮草。

等级上限保持 40，聚义厅门槛为 4 级。第八卷要求队中至少一人 38—39 级，第九至十一卷 39 级，终章 40 级。已用 40 级凡品武松、杨志、宋江配常规 +3 装备、2 级招式、300 随行兵，完成全部 36 种路线组合；测试按场补充兵力、选择集火与固守，并使用必要药品。不要求仙品队伍、指定剧情人物入队或收齐 108 将。

## 选择与结局

- 第八卷先救人、查证或截粮，必须先完成选定任务，再办理另外两项。三选一分别给予东门决战 10% 气血护盾、主将初怒减少 15、少一名援兵。
- 第九卷暗线需要先断传令，撤离少一波援军；正攻门战有两阵重甲，撤离时护送损伤降低 50%。两路奖励相同。
- 第十卷分粮两案都保障军民口粮。补给使下一场守渡战换波时存活好汉恢复 15% 气血；防守给该战开场 15% 气血护盾。
- 第十一卷先护送流民、追回口粮，分别核对两份诏书，最后确认护乡或受诏立约。查看意见、返回重看不扣物资，也不提前改线。

| 护乡 | 守渡口、救出村民、击退围泊军 | 守泊护乡 |

终章确认前列明方向，确认后固定本次正式路线。最后一战以后仍须回营核齐名册，才完成结局。后记交代具体人物的住处与职责，原有英雄、队伍和培养继续保留。

通关显示“主线已完结”，可以在梁山志重读本次结局，继续经营、培养与历练。**本轮没有重开其他结局路线、阵容快照或模拟回顾战斗功能。**

## 奖励与护送规则

第八至十二卷每卷自动结卷发招贤令 2，既定章节招贤补给另领 2，每卷合计 4、五卷合计 20。每卷灵蕴 5，合计 25；第十、十一、十二卷各发登仙印 1，合计 3。节点另发常用药品与材料。三种终章的材料和稀有奖励等值，正式存档只领一次；普通招贤概率和保底保持原值。

护送目标有独立完整度。指定射手存活且未眩晕时按间隔追射，击倒后停射，眩晕暂时停射；固守将护送损伤减半并向上取整。多波战斗保留气血、怒气、状态和完整度，不复活已退阵好汉。

出征费用在预览中显示，只在正式出发时扣除；失败或撤退仍有本次消耗。胜利先回到本战故事确认战果，再推进下一任务。回营、切页、刷新和导入存档都保留这个检查点，不会重复给奖。

## 存档与升级顺序

存档主体仍为 version 2，旧档无需重开。后五卷故事与选择使用原有进度字段，新战局记录实际波次、护盾和护送状态。普通云端上传不能倒退已有主线进度或改掉已选路线；需要回到历史存档时，仍使用明确的历史回滚操作。

**先部署新版云存档 Worker，再发布前端；本轮没有新数据库表，无须执行 SQL。** 部署沿用既有 D1、save 子域名与网关配置。

在项目根目录执行：

~~~bash
npm run test:game
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
~~~

部署后检查 `/v1/game-version` 的 `chapters` 为 `12`，`release` 与本次前端版本一致，再按现有 GitHub / Pages 流程发布前端。旧 Worker 若仍只认识七卷，新前端会在上传前提示升级并保留本机进度；文件导出仍可使用。不要通过重新执行旧 SQL 来补主线内容。

以上是发布步骤，本轮开发与本地验收不代表已经部署线上。
