# 休息一下：五幅小风景与定时轮播

这是导航和 Tech OS 共用的休息动画，共五幅可以手动选择或定时轮播的风景。画面由本项目的 SVG 和代码绘制，不加载外部视频、音乐或图片。

- 月光泛舟：小狐狸划船，船桨拨动涟漪，灯笼和萤火虫轻晃。
- 云海漫游：小兔子乘热气球漂浮，围巾随风摆动，云海缓缓流动。
- 雨窗小憩：雨点滑过拱窗，小猫静静呼吸，热茶升起蒸汽。
- 星河露营：小熊在帐篷边看书，暖灯、流星和萤火虫点缀夜色。
- 海岸骑行：鹈鹕戴着围巾沿海岸骑车，双腿交替蹬踏，车轮、海浪和路边草木联动。

“海岸骑行”沿用用户提供的 `pelican-cycle.html` 中的 SVG 画面和双段腿部蹬踏机制，不改动原始文件。它作为第五幅风景接入系统共用控件，不重复嵌入原页面的按钮或脚本；手机上调整构图，保留完整的自行车。

## 从哪里打开

- 导航首页：搜索栏下方的“休息一下”。
- Tech OS 学习工作台：顶部的“休息一下”（小屏幕显示咖啡杯图标）。
- 导航侧栏：点击“休闲”场景模式，也会打开动画。
- 首页命令面板：按 Ctrl / Cmd + K，搜索“休息”并执行。

## 怎么使用

- 播放 / 暂停按钮可以让画面停住；速度按钮在 1、1.3、0.65 倍速间切换。
- 默认每 1 分钟按“泛舟 → 云海 → 雨窗 → 露营 → 骑行”的顺序轮播，最后一幅回到第一幅。可选择每 30 秒、1 分钟、2 分钟、5 分钟切换。
- 点击画面下方的风景名称可以立即切换，并重新计时；修改轮播间隔也从完整的一轮重新计时。计时独立于动画播放速度。
- “轮播关闭”只停止自动换景，当前画面仍会动；“暂停动画”会同时暂停画面和轮播计时。重新开启轮播会从剩余时间继续。
- 轮播只累计在前台观看且已加载成功的时间。进入后台、关闭休息界面或画面加载失败时，不继续轮播，也不会返回后一次跳过多幅风景。
- 点击“休息好了”、右上角返回按钮，或按 Esc，回到刚才的页面。
- 学习工作台不因打开动画而卸载，当前选中的问题、工作模式和未提交的填写内容会保留；休息不会替你完成任务或更改学习打卡。
- 页面进入后台时自动停下，回到前台后按照原来的播放状态继续。
- 系统启用“减少动态效果”时默认静止，并关闭自动轮播；可以分别手动播放和开启轮播。
- 没有倒计时催促、没有声音，也不会因为空闲或刷新页面而突然弹出；只有主动点击入口才会打开。画面下方的秒数仅表示距离下一幅风景还有多久。
- 选景、速度、轮播开关和间隔只在本次休息中有效。关闭后再打开，从第一幅及默认间隔开始，不修改学习数据和跨端同步内容。

每幅动画按需加载，第一次选择某幅风景需要能获取站点资源。已加载的画面不依赖持续联网；是否能在重新打开站点后离线使用取决于站点缓存是否完整。加载失败时不会盲目轮播，可以手动选择已加载的风景，或联网刷新后重试。

## 开发验证

运行 `npm run test:rest-animation` 检查动画时序、骑行脚蹼与踏板联动、四种间隔和五幅循环顺序，运行 `npm run verify` 检查构建和全部自检。浏览器验证需覆盖前台轮播、手动重置、后台暂停、减少动态效果、加载失败、Esc 返回、手机布局，以及返回后学习工作台的状态。

相关文件：`src/components/rest/`、`src/services/restAnimation.ts`、`src/services/restPlaylist.ts`、`src/services/pelicanMotion.ts`。休息状态只保存在当前页面会话中，不写入跨端同步或博客内容。
