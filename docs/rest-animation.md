# 休息一下：小狐狸的月光泛舟

这是导航和 Tech OS 共用的休息动画。围着围巾的小狐狸在湖上划船，船身、船桨、灯笼、远处的云和萤火虫缓慢运动。画面由本项目的 SVG 和代码绘制，不加载外部视频、音乐或图片。

## 从哪里打开

- 导航首页：搜索栏下方的“休息一下”。
- Tech OS 学习工作台：顶部的“休息一下”（小屏幕显示咖啡杯图标）。
- 导航侧栏：点击“休闲”场景模式，也会打开动画。
- 首页命令面板：按 Ctrl / Cmd + K，搜索“休息”并执行。

## 怎么使用

- 播放 / 暂停按钮可以让画面停住；速度按钮在 1、1.3、0.65 倍速间切换。
- 点击“休息好了”、右上角返回按钮，或按 Esc，回到刚才的页面。
- 学习工作台不因打开动画而卸载，当前选中的问题、工作模式和未提交的填写内容会保留；休息不会替你完成任务或更改学习打卡。
- 页面进入后台时自动停下，回到前台后按照原来的播放状态继续。
- 系统启用“减少动态效果”时默认静止，可手动点击播放。
- 不自动计时、无声音，也不会因为空闲或刷新页面而突然弹出；只有主动点击入口才会打开。

动画按需加载，第一次打开需要能获取站点资源。已加载的画面不依赖持续联网；是否能在重新打开站点后离线使用取决于站点缓存是否完整。

## 开发验证

运行 `npm run test:rest-animation` 检查动画时序与接线，运行 `npm run verify` 检查构建和全部自检。交互需额外在浏览器检查暂停、速度、Esc 返回、手机布局，以及返回后学习工作台的状态。

相关文件：`src/components/rest/`、`src/services/restAnimation.ts`。休息状态只保存在当前页面会话中，不写入跨端同步或博客内容。
