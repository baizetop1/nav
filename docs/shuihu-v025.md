# 白泽水浒 0.25.0：兵员损耗、成长补给与高唐救援

## 对应本轮反馈

1. **兵员真正消耗**：募兵仍按每人粮草 2、碎银 3 扣除。战后分为安然归营、伤兵和阵亡；医馆只能治疗伤兵，阵亡需要重新付费募兵。复盘、累计阵亡、本地导出和云档均保存新记录。
2. **扩大统兵规模**：兵营每级提供 200 兵额，五级最多 1000；可选择 10、50、100 人一批募兵。好汉基础统兵 150，每升一级 +10，灵品额外 +50，仙品额外 +100。全军实际人数取在营人数、计划人数、阵容统兵上限三者最小值，且最多 1000。分配会遵守每名英雄的上限。
3. **体力随成长扩容**：基础上限 100；聚义厅每高于一级增加 10；最高等级的已入寨好汉到 6、11、16、21、26、31、36 级各增加 5。当前最高上限 175。扩容不会立刻补满体力；离线恢复、村酒、顶部显示和存档校验统一使用实际上限。人物经验仍使用之前的递增曲线。
4. **地图可操作**：道路名称现在是路线预览按钮；每个地点卡有“前往此地”或“查看开放条件”。未满足条件的地点可查看障碍，不能绕过路障。当前所在地点可直接查看事务。
5. **建寨志清晰计数**：截图中的 4/5 对应“粮道畅通”尚未完成，原列表却在“全部”中排除当前目标。本版完整列出五项，分别显示已达成和已领奖数量；未完成的出征目标提供定位按钮。没有把实际没做过的目标直接标记完成。
6. **后续主线**：第六卷《高唐救援》从第五卷粮仓接续，新增 7 处地图、3 场必经战役、1 场可选截援战，以及可选辨阵支援、接应结卷。第七卷尚未开放。
7. **克制的奖励渠道**：每日勤勉荐书、每期军功兑换、每月聚义酬劳，具体次数与门槛见下表。
8. **外传人物**：增加王进、扈成、栾廷玉。三人都有独立立绘、四项招式、专属兵种、坐骑及凡灵仙培养。正册仍为 108 将，外传现有 4 人，总计 112 名可培养好汉。普通招贤概率与保底不变。

## 伤亡与出征成本

沿用现有军令和战损比例：稳扎稳打基础损耗 12%，强攻 24%，固守 6%，再结合剩余气血、胜负和寨务地形调整。计算出的减员中，胜利按 20%、撤退按 35%、失败按 45% 向下取整计为阵亡，其余为伤兵。人数很少或损耗很轻时可能没有阵亡；不会凭空扣除未参战的兵员。兵员减员总数不超过实际随军人数。

粮耗按实际人数计算，取消出征预览不扣费，失败和撤退不返还出发消耗。普通带兵历练每两人消耗一份粮；寨务、周本、领地与主线另有各自固定粮耗，战前预览显示完整费用。英雄本人仍只退阵，不永久删除。

兵力的战斗增益采用递减：每位英雄分得不超过 34 人时沿用原属性加成；超过部分按平方根递增。实际兵数仍用于消耗和伤亡，不能靠堆兵把所有战斗数值同比放大。三套阵容预设、精英战、每日材料本、周本、地图副本和主线使用同一统兵规则。

## 第六卷路线

庄后粮仓 → 高唐行营 → 高唐城外 → 牢城外院 → 高唐内城 → 城南接应点。

- 行营整备需要聚义厅 4、兵营 3、医馆 2，不再扣一次建设材料。
- 城外外哨：队中一人 30 级，体力 12。
- 可选静庐辨阵：交药草 4，终战敌军攻击降低 15%。
- 可选援道截骑：外哨得胜后开放，队中一人 31 级，体力 12；完成后终战移除援骑。
- 牢城接应：队中一人 32 级，体力 14。
- 合围高唐：队中一人 34 级，体力 18；高廉会蓄势护阵，可打断。
- 每战粮草为 8 + 向上取整（实际兵力 / 2），独行也需固定粮草 8。
- 胜利后在原地确认战果，最后到城南接应点结束本卷。结卷奖励招贤令 4、登仙印 2、灵蕴 6；柴进相识和信物按已有成长保存，不重置人物。

战前支援会改变真实敌军数量与攻击，战中保存、刷新不会再次叠加。等级仅是入场条件，不保证任何阵容必胜。测试中林冲／鲁智深／宋江的三条完整通关配置为：

- 35 级凡品、300 人，完成辨阵与截援；无装备加成。
- 40 级灵品、600 人，跳过两个支援直接攻城；无装备加成。
- 40 级灵品独行，基础与进阶招式 2 级，完成两个支援；无装备加成。

这些是通过测试的示例，不是强制队伍。实际战况仍取决于培养、军令、技能、药品和阵容。连续战役要治疗伤兵、重新补员；阵亡不会因下次出征而恢复。

## 存档、验证与发布

外层存档仍是 version 2，名册版本为 5。旧 108/109 人名册按历史 introducedIn 自动补入未获得角色，保留已有培养、装备、剧情和兵员；加载旧档不会免费招兵、治疗或补满体力。阵亡与悬赏记录仅在对应行为发生后产生。

**必须更新云存档 Worker；无需新增数据库表或执行迁移 SQL。** 服务字典与前端一起升级，`/v1/game-version` 应包含 release 0.25.0、heroes 112、rosterVersion 5、chapters 6。旧页面不能覆盖较新名册的云档。

验证命令：

```bash
npm run test:all
npm run build
```

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

本轮开发没有自动提交、推送、部署或写入生产云档。原来的第三至第五卷与 0.24.0 改动一并保留。
