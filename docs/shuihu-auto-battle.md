# 白泽水浒 · 自动交战（0.2.5）

> 0.4.0 新增全人物技能等级、人骑羁绊、历练首领蓄势与阵容调整；新规则及更新顺序见[全人物养成](shuihu-growth.md)。下文是基础交战的历史实现说明。

> 0.3.2 补充：现在可在战斗页选择“手动技能 / 自动技能”，默认手动；药品始终手动。详见[技能释放模式](shuihu-skill-modes.md)。下文是 0.2.5 的基础交战说明，其中“我方技能不会自动使用”现仅适用于手动模式；页面布局与日志位置以 0.3.1 的[固定一屏布局](shuihu-fixed-screen.md)为准。

本次把战斗从手动回合指挥改为「自动普攻 + 手动技能 + 手动用药」。不是每隔几秒自动点击一次旧的回合按钮：旧 `turn` 指令已经移除，各单位都有独立的出手时间。

## 怎么玩

1. 剧情战、历练或际遇交战开始后，双方自动普攻。速度越快，出手间隔越短，不必逐次点攻击。
2. 每位我方人物的技能在自己的气血条下。怒气足够时点击释放，即刻生效，不等待其他人行动；释放后该人物调息 5 秒，其他人的技能不受此冷却影响。
3. 金创药给存活且气血比例最低的同伴疗伤；回气散给怒气最低且需要回气的存活同伴；解毒丹优先清除一位同伴的中毒、流血、破甲、眩晕，不清除有益状态。
4. 药物共用 3 秒间隔。药效立即生效，不停止或代替自动普攻。没有合适目标时按钮禁用，不扣道具。
5. 我方技能和物品均不会自动使用。怒气不足、调息中、眩晕或退阵的好汉不能施放技能；药物和治疗技能不复活退阵单位。
6. 可随时暂停或撤退。胜负判定后，点「收获战果，继续前行」或「收兵，再作安排」结算，原有奖励防重复规则不变。

「智取生辰纲」仍是观察、选择的独立计策玩法，不被转换成自动攻击。招募、队伍、装备、人物相识与两卷剧情不重置；剧情临时助阵不等于招募入寨。

## 自动推进的边界

- 新交战自动开始；从本机存档、导入或旧存档迁移接续的战局，先暂停，点击「继续交战」才推进。
- 主动暂停、切后台、离开战斗页时，普攻、状态持续时间、技能和药物冷却一起停止；回到页面后需要明确继续，不补算离线时间。
- 浏览器调度中断超过 1.5 秒时暂停，避免恢复后突然连打。普通定时回调最多推进 1 秒。
- 战斗最多持续 180 秒有效交战时间，仍无法分胜负时撤出；暂停时间不计入。
- 战斗内没有新的联网、账户、付费或跨设备同步；仍沿用独立本机存档。

## 实现与存档

- `battle.js` 使用 `mode: realtime`、累计有效毫秒 `elapsed`、每人的 `nextAttackAt`、技能 `skillReadyAt`、药物 `itemReadyAt`；按事件的实际先后处理普攻和状态，不使用全队轮流行动的回合队列。
- 伤害、装备与被动属性沿用既有数据；敌方按自身出手节奏使用可用技能。我方普攻只增加怒气，主动技能由玩家决定。
- 数据中的状态时长单位转换为每单位 2 秒；实际战局保存到期时间和持续伤害时间。中毒可叠加，其他同类状态延长时效。
- 总体存档版本仍为 2。读取旧 `round` 战局时先完整校验，再转换为实时战局；保留双方气血、怒气、战报、上下文、药物和剧情进度。写入前沿用有效备份机制，备份是滚动的「上次有效存档」，不是永久历史库。重要存档请另行导出。
- 实时战局须由 0.2.5 或之后支持该结构的版本读取，不应回退到旧游戏脚本继续战斗。
- 画面每 200 毫秒更新一次，普通推进约每秒落盘；技能、用药、暂停、结局立即尝试保存，离开/刷新时补存尚未落盘的进度。强制结束浏览器仍可能丢失最近约一秒的普通推进。
- 存储配额不足时保留本页内存进度并提示导出；跨标签冲突立即暂停并停止写入，不覆盖另一页。

## 页面与操作

- 战斗时只显示江湖、梁山志、存档这三个可用导航，隐藏不可用的管理入口。
- 显示双方气血、怒气、出手倒计时、状态持续时间、我方技能、敌方当前出手意图与最近一条战报。完整战报默认折叠。
- 时钟更新只修补已有 DOM，不整页替换按钮；保留键盘焦点、按住按钮时的节点与用户展开的战报。状态行高度固定，避免状态变化挤动技能按钮。
- 技能/用药按钮保留中文标签与本地 SVG，小屏触摸目标不小于 44px，无全屏遮挡层。
