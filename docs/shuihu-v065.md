# 0.65.0 战斗结束提示

战斗结束后自动显示胜利、失败或撤退提示。两个按钮直接显示在弹窗中，不必翻到战斗页面末尾。

- **领取并继续**：胜利后领取奖励、保存结果并返回游戏，不再打开完整结算页。
- **结算并返回**：失败或撤退后结算兵损并返回；演武使用“完成并返回”。
- **查看战报**：先完成同一次结算和保存，再打开战斗复盘，可切换查看所得。

提示本身不发奖。两种选择都使用原有 `finishBattle` 事务，连续点击不会重复领取。刷新时尚未结算的战斗会再次提示；已结算的战斗不会再次发奖。保存失败时仍显示结算页中的未保存提醒。

本次只调整前端交互，不修改战斗、掉落概率、奖励或存档结构，不需要新增数据库迁移，也不因本次改动而要求更新 Worker。此前版本的 Worker 升级要求不受影响。

验证命令：

```sh
npm run test:shuihu-battle-outcome
npm run check:shuihu-battle-outcome
npm run test:game
npm run build
```

浏览器检查需要安装 Playwright，并可通过 `SHUIHU_PLAYWRIGHT_PATH` 指定已有安装，通过 `SHUIHU_GAME_URL` 指定本地页面。检查使用独立浏览器环境，不读取玩家存档。
