# 白泽水浒 0.2 · 逼上梁山

## 本轮范围

依据六份设计文档，按总路线图先完成 0.2；不是一次性实现 0.3～1.0。0.1 的探索、招贤、装备、日常和存档均保留。

新增内容：

- 16 个地点：东京、教头旧居、大相国寺山门、寺院、菜园、北官道、野猪林、沧州、李小二酒铺、草料场、雪路、山神庙、柴进庄、客舍、南下水泊路、青州行旅道。
- 林冲《风雪归途》主线、鲁智深《禅杖护友》支线、柴进《雪中留客》、杨志《失意不失义》。记录林冲由隐忍至决绝的心境，三个关键战斗由对应人物临时参战，不会自动入寨。
- 正式名册新增柴进、杨志及各自两个技能、信物、专属招贤令。林冲、鲁智深原本已在名册中，不重复新增，也不撤销旧存档中已相识或已拥有的状态。
- 柴庄护送、青州护道两处 20 级历练，每日各三次，体力 15，信物掉率各 20%；另提供野猪林、山神庙的当地重游入口，与原历练渡口共享次数。
- 六份第二卷主线差事、四个路上事件、分卷目标与梁山志、进行中剧情的下一处地点和前置提示。
- 完成山神庙往事后，到郓城铁匠铺「请教风雪淬炼法」，开放 +6～+10。每次消耗碎银、精铁、强化符，成功率 80%；失败不降级、不毁装备。基础 +1～+5 保持必成。

当前总量：46 个地点、14 名好汉、6 条人物剧情、34 个技能、55 种道具、20 件装备、24 个事件、7 个重复历练。每日任务仍为原来的 12 种模板，每日抽取三份；坐骑任务尚不派发。

## 从哪里进入第二卷

1. 先完成第一卷：景阳冈与生辰纲主线、至少三名正式好汉、十次历练胜利、威望 150。
2. 前往「梁山脚下 → 渡口」，点击「东京城门」。第一卷未完成时此入口隐藏。
3. 在「教头旧居」与林冲叙过姓名；再从东京经大相国寺山门进入寺院、菜园，完成鲁智深的相识。
4. 回东京，经北官道进入野猪林，先推进林冲的押解往事，再让鲁智深护友；胜后记下相助之情，继续林冲剧情前往沧州。
5. 李小二酒铺 → 草料场 → 风雪山道。察看雪中脚印，才会出现山神庙入口。听清真相、完成林冲剧情战后，领受投庄书。
6. 去柴进庄，在客舍交书，回庄中应下护送之约；经南下水泊路回渡口，完成林冲的归途。
7. 从东京北官道可转入青州行旅道，完成杨志护道往事。

四段往事均完成后，自动结算第二卷奖励（威望 50、功勋 60、招贤令 2），只领取一次。不要求先把这四名人物全部招进队伍。每段剧情的信物与任务酬劳也是独立的一次性奖励。

走到条件不足的地方时，看地图中的「进行中的往事」及「差事」提示；可以离开、准备后再回来。剧情战撤退或失败保留当前故事步骤，可重试；已用药物不返还。

## 存档与发布

- 内容版本为 0.2.0，存档格式从 version 1 升到 version 2。原有英雄、队伍、装备、道具、招募保底、剧情和日志保留；只把柴进、杨志补为「未闻」。新人物不会因升级直接入寨。
- 首次成功保存升级后的进度前，会备份原始旧存档。缺失原有好汉的坏档、未知未来版本仍会拒绝，不静默清空。
- 升级前建议导出存档并关闭其他游戏标签页。旧版本页面无法读取新版存档；回退代码前应先导出新版进度，再恢复旧备份。
- 依旧只存当前浏览器，通过导出/导入 JSON 手动跨端迁移，不是自动云同步。不会读写博客、学习系统或 GitHub Token。
- 入口仍是导航首页「白泽水浒」与命令面板，部署路径仍为 `/nav/game/`。模块与样式带版本参数，导航 Service Worker 继续排除游戏路径。
- 本地开发：在导航项目目录运行 `npm run dev`。本次不代提交、不推送 GitHub。
