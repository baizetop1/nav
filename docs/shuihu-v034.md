# 0.34.0 手机分区与主线接续

## 页面结构

- 手机主导航固定为寨子、江湖、好汉、行囊、更多；招贤、打造、历练、差事、山河、梁山志、存档从“更多”直接进入。
- 寨子首页只保留当前主线与十二个功能入口。营建、募兵、出征配置、远征、寨事、生产、目标、补给等各自独立显示，顶部可切换或返回总览。
- 好汉养成分为名册、阵容、经验、兵种、品阶、招式坐骑、天赋装备、任务、档案。手机名册每页四人，点头像打开独立档案，筛选可展开。
- 招贤、打造、存档、每日材料本、周本、精英与排名独立分区。材料本可选路线；地图可按区域查看，也可选择完整地图。
- 日志默认折叠，仍可展开阅读。长清单、完整剧情和展开的详情保留必要滚动，不缩小操作按钮来强塞内容。

## 主线引导

- 寨子首页和江湖剧情顶部显示当前卷、未完成目标与下一目的地，可直接按真实道路前往。
- 第一卷明确指向：三碗不过冈结识武松 → 枯树林查看脚印 → 虎踪继续追踪 → 密林深处打虎并确认战果 → 郓城酒肆打听东溪村 → 七星聚义 → 黄泥冈取纲。
- 剧情中断、切页或重载时，目标由已有存档状态重新推导，不需要重做剧情。道路未开放时先指向前置任务；不会跳过条件或自动领取奖励。
- 到达剧情所在地后收起重复提示，优先显示剧情文字及选择；当地闲谈、已完成故事和自由行路分开折叠。
- 其余卷根据卷终条件、剧情步骤和道路前置推导目标；无法解析的经营条件回到梁山志查看具体目标。第二卷跨人物前置已加入验证。

## 更新方式与兼容

- 本次为前端更新，沿用原存档格式，不改抽取概率、经验、伤亡或奖励。无需数据库迁移，也无需仅为本版本更新 Worker。
- 网站按原有 GitHub 发布流程更新；本机开发服务器刷新即可体验。
- Android versionCode 34 / versionName 0.34.0，使用原签名覆盖安装，保留 App 本机数据。浏览器存档仍需导出后在 App“更多 → 存档 → 导入文件”选择 JSON，或接续云档。
- APK 构建与密钥备份见 [Android 说明](../android/README.md)。不要卸载旧 App 来升级。

## 验证

新增 `npm run test:shuihu-mobile-pages`：真实命令验证第一卷寻迹、七星路线、重载接续、卷终条件与第二卷剧情前置；检查每个入口只渲染所选分区。原有界面测试改为进入相应分区验证，原玩法测试保持运行。

浏览器隔离环境覆盖 360×640、390×844、1440×1000，以及 APK 本地 HTTPS 路径下的离线启动、原生导出桥接、文件导入和重载。Android 系统文件选择器及厂商 WebView 尚未连接真机验证。
