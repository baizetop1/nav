# 0.66.0 统一结束提示

沿用战斗胜负提示，把以下待结算流程改为自动弹出小提示，按钮直接可见：

- 黄泥冈计策成功、失败（首次剧情与计策副本）。
- 江湖游历、短程远征完成五段路线。
- 三波寨防、三队接力完成三场战斗。
- 分队归来、寨事外派到达归程时间。

选择“领取并继续”“接回并继续”或“结算并返回”，直接执行原有结算；另一按钮可在结算后查看所得、计策经过或分队兵损。刷新仍会提示尚未结算的结果。未走完的路线不会自动撤回，仍需玩家决定继续还是提前收队。

普通领奖、打造、购买等原本弹出收获页的操作，现在先显示简短的已保存提示。点“继续”返回，点“查看明细”打开原收获页；查看明细不会再次执行操作。招贤人物展示和出征、购买等操作前确认沿用原流程。

同一时间只显示一个结果弹窗。最后一战结算后，整趟远征的领取提示会接着出现；查看战报时会等到关闭后再提示。战斗、计策或连续战役占用队伍时，不抢先执行被规则禁止的外派领取。存档冲突时停止操作，写入失败时保留原未保存警告。

不修改掉落概率、奖励、消耗或存档结构。本次无需数据库迁移，也不因这次界面改动要求更新 Worker。

验证：

```sh
npm run test:shuihu-completion
npm run check:shuihu-completion
npm run check:shuihu-battle-outcome
npm run test:game
npm run build
```

浏览器验证通过独立环境完成，不读取玩家存档。需要 Playwright，可通过 `SHUIHU_PLAYWRIGHT_PATH` 指定已有安装。
