# 白泽水浒 0.48.0：浅青界面与分组菜单

## 界面

以本轮用户提供的第一张灵界菜单截图为主要参考：浅青背景、白色浮层、灰绿按钮、细边框；分类只用小竖条标色。标题使用墨绿，减少大面积黄色。日间背景为 #eef6f3，夜间保留原深色主题；浏览器顶栏同步日夜颜色。

页头和手机底栏的“更多”打开同一浮层，关闭后返回原页面。原页面的输入、当前分页与人物选择保留。菜单按历练、寨务、好汉、其他分四组，每组三列、共24个已有功能入口；主线、地图、周本、募兵、招式等直接到对应分区。

普通竖屏同时显示四组。视口高度不超过700px时，通过顶部分类按钮切换，每次显示一组；没有把字号和触摸按钮继续缩小。列表和复杂页面仍使用现有分区与分页。

菜单独立布局，不经过通用弹窗分页转换。支持关闭按钮、Escape和点击遮罩，关闭后焦点返回打开菜单的按钮。战斗中打开菜单立即暂停并更新底页状态，只有主线、存档和梁山志可访问，关闭后不会自动续战。

- 分组菜单：手机、横屏、桌面及短屏切换边界逐项检查24个入口、三种关闭方式、输入保留、战斗禁用/暂停和无溢出。
- 生产构建通过。浏览器记录与截图见 artifacts/menu/。
