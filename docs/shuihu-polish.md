# 白泽水浒 0.14.1：回寨待办与流程补齐

## 本轮完成

- 寨子首页汇总外派进度、待办来报、可领取建寨与差事酬劳、生产、告急据点和伤兵。点击跳到对应区域，折叠的据点详情会自动展开；提醒不扣资源、不自动领奖。
- 阵容预设不能召回尚未接回的外派英雄，即使十分钟已经到期也需要先手动接回。启用失败保留原阵容、资源和存档。
- 编队和生产任职列表标出并禁选外派者，好汉卡显示外派状态，主事按钮同步禁用。外派名单仅列出满足等级且没有任职的好汉，无人可派时说明原因。
- 游戏状态复制兼容缺少 structuredClone 的环境，保留嵌套对象、空数组位置、undefined 和共享引用，替换 Object.hasOwn 与数组 at 依赖。装备预览使用同一复制入口。
- 服务器演武榜和云端进度榜分别显示加载、失败状态。演武刷新失败不再把提示放到另一个榜单；旧结果被清除，避免把上次数据误当本次刷新成功。

## 存档与发布

沿用 0.14.0 存档字段，没有新增数据库迁移或云端能力标记。本版静态页面通过现有 GitHub 发布流程更新。若 0.14.0 的云端更新尚未上线，仍须先完成 [0.14.0 升级说明](shuihu-management.md) 中的排名表迁移和 Worker 部署。

## 验证

完整自检与生产构建通过。新增测试对比原生与兼容复制的整场战斗结果，验证旧存档升级、文件往返、预设外派限制、待办只读和榜单提示隔离。隔离浏览器移除三个接口，覆盖手机编队、待办跳转、外派归来、装备转交、云端演武、榜单失败，以及导出后导入另一个本机编号并重载。测试云端使用真实 Worker 代码与内存 SQLite，不写生产存档。
