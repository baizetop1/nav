# 白泽水浒 0.21.0：第三卷《梁山初聚》

本版将第三卷接成完整主线：安寨 → 粮木补给（顺序自选）→ 水陆接驳 → 守寨 → 立约。本文记录 0.21.0 的第三卷实现。后续 0.22.0 已开放第四卷《三山聚义》，见 [第四卷说明](shuihu-volume-four.md)。

## 入口与地图

第二卷完成后，从江湖 → 金沙渡前往聚义议事坪。寨子和梁山志新增第三卷目标板，点击目标可在江湖地图定位，不自动移动、领取或消耗资源。

全部八处地点、相邻道路、解锁条件在全图中提前展示，即使前卷尚未完成也可以查看：

| 地点 | 事务和开放方式 |
| --- | --- |
| 聚义议事坪 | 进入第三卷的中心；由金沙渡进入 |
| 寨民新居 | 确认安置，需要聚义厅 2、农田／伐木场／医馆各 1，三名已入寨好汉 |
| 东岸粮仓 | 护送粮队，至少一位出阵英雄 10 级 |
| 青石材场 | 清理林路，至少一位出阵英雄 10 级 |
| 芦苇望哨 | 可选侦察，在寨子改为英雄独行后探看；无需特定英雄 |
| 水陆接驳口 | 粮道或木道任一完成后开放，至少一位出阵英雄 12 级 |
| 外寨栅门 | 安寨、粮道、木道、接驳全部完成后开放，主力至少 15 级 |
| 水泊盟亭 | 守寨胜利并确认战果后开放，在此立约完成第三卷 |

粮道、木道可以互换顺序，也可先打一条路、再夺渡口、再补另一条路。抵达地点后“查看此地事务”，开始任务，再选择行动。胜利后回到当地确认战果领取酬谢；没有自动替玩家选取或提交剧情奖励。

## 经营与旧进度

- 已有建筑等级与已入寨好汉直接满足安寨条件，无需重建、重复招募或花材料“补交”已有进度。
- 不要求招到林冲、宋江等特定人物；可以用玩家自己的阵容推进。
- 本卷战役使用实际出阵英雄与乡勇。支持独行、带兵、军令、专属部队、地形专长、治疗和首领蓄势；前两卷临时助阵规则保留。
- 招贤、打造、训练、生产与存档仍从原有入口直接访问；第三卷地图提供额外任务、情报和探访酬谢。
- 不提高等级上限，不重算旧档等级或经验；凡、灵、仙养成继续沿用。

## 出征与情报

| 战役 | 主力最低等级 | 体力 | 地形 |
| --- | ---: | ---: | --- |
| 粮道先行 | 10 | 8 | 平原 |
| 林路取材 | 10 | 8 | 林地 |
| 渡船连营 | 12 | 10 | 水域 |
| 守住归处 | 15 | 12 | 平原 |
| 进阶守寨演武（可选） | 30 | 20 | 平原 |

每次粮耗为 `8 + 向上取整(实际随行人数 / 2)`；独行消耗 8 粮。统一使用出征准备弹窗，可看敌情、消耗、实际部队，并调整阵容；取消不扣费。确认出发即扣体力和粮草，撤退或失败不返还，可以重新准备再战。普通主线没有每天次数限制；已确认胜利的任务不能重复打取奖励。

芦苇望哨只需侦察一次，情报保存在本档。本卷水战、守寨、进阶演武的敌方气血、攻击、防御、谋略按原值 85% 生成，速度不变。情报可选，普通主线不以此为必需条件。

“进阶守寨演武”在第三卷卷终后开放，首胜另奖登仙印 2、灵蕴 6、武学残页 10。适合已有高级主力的玩家；不影响第三卷完成，也不参与周本排行。

## 酬劳与卷终

七段事务覆盖安置、四场主线战、立约和进阶演武；完成标记、剧情步骤与酬谢通过既有存档体系保存。战斗胜利和当地领取分别记录，战斗结束后刷新不会重复打，确认完成后不能重复领取。

完成当地物资路线后增加三个探访好处：

- 东岸粮仓：每日村酒 1。
- 青石材场：每日碎铁 2。
- 水陆接驳口：每日精制草料 2。

使用现有每日日期切换，重复领取会拒绝。第三卷立约完成时额外给予碎银 600、招贤令 3、灵蕴 4；差事页有三份相应主线酬劳，可另外确认领取。

## 存档与发布

新增内容使用已有地图访问记录、剧情步骤、flags、每日 counters 和战报字段，存档版本继续为 2，**无需增加数据库表或执行迁移 SQL**。

**Worker 必须更新至 0.21.0**：旧版本没有第三卷地图、剧情和战斗规则。客户端上传带第三卷进度的存档前检查 `/v1/game-version` 中的 `chapters >= 3`；不支持时先提示更新，不向旧服务提交新档。

发布顺序：先部署 Worker，再推送 GitHub 发布前端，多设备刷新到同一版本。

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

本轮仅开发与本地验证，未推送、部署或修改线上存档。旧进度无需清空。
