# 0.63.0 梁山渡口与换卷指引

梁山脚下、金沙渡接入场景页，新增一张水泊渡口插画，两地共用。结合先前场景页，目前覆盖 21 个地点；并非十二卷均已插画化。

现场描述区分取纲落脚、第一卷完成后收到东京来信、已开始林冲故事后候船、林冲离岸、第二卷完成等阶段。林冲返回金沙渡的原有末段对白显示本人头像，仍要求先完成柴进托付；选择和一次性奖励沿用原逻辑。

“渡口事务”显示当前卷的未完成条件。第一卷的入寨人数、历练次数、威望显示真实数值，可直接进入招贤与历练。未满足条件时，东京道路仍锁定。完成后显示第二卷目标，主线指引会沿真实路径前往林冲所在地点。已完成项目折叠显示，渡口人物入口仍保留。查看事务或场景不会修改旗标、发放奖励或自动结卷。
