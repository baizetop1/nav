# 0.33.0 紧凑界面与 Android 安装包

- 手机正文 13px、辅助信息 12px；桌面正文 14px，标题、卡片与资源数字同步压缩。表单保留 16px，手机主要按钮保留至少 44px 高度。
- 手机日志默认收起，点击展开/收起并记住选择；战报继续记录，可冻结阅读。桌面继续使用侧栏日志。
- 寨子首页统兵、体力成长规则折叠展示，资源与待办更靠前。
- 新增 Android 原生 WebView 外壳，内置完整游戏，支持系统文件导入导出、返回和后台暂停。
- 云存档名册最低服务版本固定为 0.32.0，避免纯界面升级导致提示误导。不修改抽卡概率、人物、成长或存档格式。

APK 构建、安装与迁移步骤见 [Android 说明](../android/README.md)。前端变更需正常发布网站才能让线上浏览器生效；APK 需发送安装包安装。本次无需新增数据库表。
