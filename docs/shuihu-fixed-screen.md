# 白泽水浒 0.3.1 · 固定一屏与江湖日志

## 布局

- 游戏外层始终占用当前可用的一屏，不再随功能内容把整个网页拉长。
- 顶部标题、资源条、导航和底部存档入口保留固定区域。
- PC：左侧导航、中间当前功能、右侧江湖日志。手机竖屏：上方七个图标与文字导航、中间当前功能、底部江湖日志；七个入口同时可见，不必横向找按钮。
- 手机横屏或较矮的宽窗口采用右侧日志，避免上下两块挤占高度。键盘缩小可用高度时压缩日志区域，表单仍可在主区域内滚动操作。
- 长剧情、好汉列表、存档设置等只在中间功能区内部滚动。日志列表独立滚动，切换功能、战斗刷新和打开/关闭招贤弹窗都不改变日志区域的位置。
- “一屏”指固定框架，不是把所有文字和按钮缩小到同时显示；小屏仍需要在相应区域内滑动。

## 日志行为

- 江湖行旅、招贤、战斗、计策与普通操作反馈汇入固定日志区，主功能区不再重复摆放交战日志。
- 默认跟随最新记录；向上阅读历史后，新记录不强制拉走当前位置。右上角“回到最新”只滚动日志，不移动主功能。
- 日志展示最近 200 条。切换江湖、好汉、行囊、招贤、差事、梁山志、存档时保留当前日志及其阅读位置。
- 切换本机存档、确认导入、另开新卷时重建日志，避免把不同存档的经历混在一起。
- 日志是展示层，不改动游戏存档格式。重载页面后从已有江湖记录和当前战局/计策恢复；已结束战斗的逐条过程只在本次页面会话保留，主要结果仍在原有江湖记录中。既有“梁山志”页面保留。
- 不收集云端密钥、Token、导入原文或后台响应到日志；错误和存储风险仍在对应功能中明确提示。

## 验证与边界

- `npm run verify`：构建和全部 33 组自检通过，包括新增 `test:shuihu-viewport`。
- 浏览器模拟验证：1920×1080、1440×900、1024×768、768×1024、390×844、320×568、844×390、640×360、320×360；验证主页面不产生整页滚动、日志固定、各标签可操作、独立滚动、短屏表单与视口恢复。
- 回归自动交战、技能/药品触控、暂停/接续、招贤弹窗、本机多存档、导入确认、多标签冲突和模拟云端接续。浏览器测试未向真实云端或 GitHub 写入数据。
- 这次是布局更新，不改变剧情、战斗数值、招贤概率或存档版本（仍为 2），也没有部署云端存档服务。
- 实际手机的输入法、浏览器工具栏与系统手势仍建议上线后复验；先前明确暂缓的旧内核 `structuredClone` 兼容问题没有纳入本次更新，详见[已知问题](shuihu-known-issues.md)。不要为更新界面清空站点数据或 IndexedDB。
