# 白泽水浒 0.38.0 · 路线首领与战法搭配

本次继续完善江湖游历：路线首领需要不同应对，六项新战法产生实际触发效果，路口选择会影响之后的补给与敌阵。入口仍是寨子总览的“选择游历路线”。

## 三条首领路线

- 青石古道：伏路箭魁蓄势 3 秒后发动号令齐射。号令手仍在阵时攻击全队；击倒后排号令手，齐射只打前位。
- 芦荡渡口：覆舟渠帅蓄势 4 秒发动回潮浪袭。固守军令除既有影响外，额外减少本招 55% 伤害。
- 断崖粮道：护卫存活时，断崖寨主受到普通攻击减伤 45%，技能不受此机制减伤。寨主蓄势 3 秒后攻击前两名在阵好汉。
- 三种首领均能直接打断，也能在绝招发动时通过眩晕令招式落空。首次蓄势从战斗 2 秒开始，之后每次施展/直接打断后等待 10 秒再蓄势。
- 手机首屏显示双方气血摘要、倒计时、简短应对提示与固守、集火护卫、留招打断按钮；护盾显示在人物气血旁。

## 六项新战法

- 固守反击：固守或护阵中受到普攻，反击 60% 自身攻击；每人间隔 3 秒。
- 回春护体：招式有效治疗的 40% 转为受疗者护盾，上限 15% 最大气血。满血溢出、药品不触发。
- 乘隙追击：普攻后敌人低于半血，追加 40% 攻击伤害；踏影行军使其提高至 70%；每人间隔 3 秒。
- 截势乘胜（古道发现）：直接打断首领后，存活队友怒气 +12，施招者追加 80% 攻击伤害。
- 济困振气（水路发现）：招式有效治疗使受疗者怒气 +8；每人间隔 3 秒。
- 借盾破阵（山路发现）：普通攻击消耗自身护盾造成等值追加伤害，单次最多消耗最大气血的 10%。

追加伤害不再次触发上述效果，不形成递归追击。护盾可吸收直接伤害与中毒/流血。战法离开本趟后失效；护盾和触发冷却按每场战斗重新初始化。

新游历初始 11 项战法，完整 20 项；每条路线首次完成发现 3 项。已经通关的路线在下一趟自动拥有对应的新候选，不必重刷首通。界面显示已成形的组合和还缺哪项，战后复盘记录触发次数、护盾吸收量、首领施招及受阻次数。

## 保存兼容与上线

旧 0.37.0 正在进行的游历沿用旧战法候选与首领规则，新出发的游历启用第二版规则。路线、事件选择、护盾、冷却和蓄势时钟进入原有存档 JSON；刷新不会补算离线战斗。

**需要更新 Worker，无需新增 D1 数据库表或执行迁移。** 新服务增加 `journeyTactics: 1`。旧服务上传前会被客户端拦截；新服务拒绝旧客户端覆盖第二版游历记录。本次开发没有执行部署或推送。

Git Bash 在原项目根目录依次运行：

```bash
cd /f/nav-main/nav-main
npm ci
npm run test:all
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
curl https://save.baizeone.top/v1/game-version
```

确认响应 `release` 为 `0.38.0`，含 `journeyTactics: 1`，再推送前端：

```bash
git status
git add public/game cloud/shuihu package.json scripts docs
git diff --cached --stat
git commit -m "feat: add journey boss tactics and branching events"
git pull --rebase origin main
git push origin main
```

若 rebase 提示冲突，先解决冲突再继续，不要强推。尚未提交的前几版游戏模块与测试也需要一并提交，避免发布缺少依赖。
