# 白泽水浒 0.23.0：第五卷《三打祝家庄》

第五卷已实现完整流程：行营整备 → 查清迷径 → 一打试阵 → 断援或断粮 → 二打破门 → 三打内院 → 战后安置。新增九处地图、九段事务、四份主线差事和四类敌人。本作采用改编情节，不安排剧情强制失败，也不要求先招到指定好汉。

## 入口与营建

完成第四卷后，从三山联合营前往独龙冈行营。寨子和梁山志显示第五卷目标板，可直接定位目标地点。地图提前展示全部地点、道路和门槛，查看不扣资源、不自动开始剧情。

行营整备需要聚义厅 3 级，农田、伐木场、医馆各 2 级。已有建设直接满足条件，不重建、不重复付费。三打内院需要聚义厅 4 级。

| 地点 | 事务或用途 |
| --- | --- |
| 独龙冈行营 | 确认已有营建，连接全卷各路 |
| 盘陀迷径 | 独行辨路或付费请向导 |
| 祝庄外哨 | 一打试阵，胜后开放援路、粮道和安置所 |
| 东援路 | 可选截断援军 |
| 西粮道 | 可选截住军粮；与东援路至少完成一处 |
| 庄外安置所 | 可选救助百姓，获得内应情报 |
| 祝庄前门 | 二打破门，对阵栾廷玉 |
| 祝庄内院 | 三打合围，对阵祝彪；实际敌情由准备决定 |
| 庄后粮仓 | 战后安置、确认卷终，之后每日领取药草 2 |

招贤、打造、训练、生产等功能继续从原有入口直接访问。地图提供额外主线、战备和战后探访收益。

## 探路与可选准备

查清迷径有两种方式，任取其一：改为英雄独行后辨路，不消耗物资；或付碎银 300 请向导，不必切换出征方式。确认后获得相同路线情报，结识石秀并获得信物 2。已经入寨的石秀保留原培养进度。不能重复领取或重复支付。

一打胜利并确认战果后，东援路、西粮道和安置所开放。东、西两路任选一条完成即可二打；另一条可以在二打后、三打前回来补做。

| 准备 | 办理方法 | 对三打内院的实际影响 |
| --- | --- | --- |
| 截断东援 | 东援路作战，胜后确认 | 移除祝庄援骑，敌人由 3 名减为 2 名 |
| 截住西粮 | 西粮道作战，胜后确认 | 敌方最大气血、攻击各降低 10% |
| 庄外济困 | 交付药草 4、粗布 4 | 敌方防御降低 15% |

准备可以叠加，只影响三打内院，不影响一打、二打、日常本或周本。第四卷的三山支援仍只用于第四卷联合守寨，不带入第五卷。

准备内容在终战出征弹窗中列出，预览中的人数和属性已计算实际影响；战斗日志也记录生效项目。战中保存属性快照，重新载入不会重复削弱敌人。

二打和济困分别可结识孙立、获得少量信物，相识不会自动招募、替换阵容或重置已有英雄。物资不足时整次操作拒绝，不扣部分材料。

## 战斗门槛

| 战役 | 队中至少一人达到 | 聚义厅 | 体力 | 地形 |
| --- | ---: | ---: | ---: | --- |
| 一打试阵 | 24 级 | 3 级 | 12 | 林地 |
| 截断东援 | 26 级 | 3 级 | 12 | 平原 |
| 截住西粮 | 26 级 | 3 级 | 12 | 林地 |
| 二打破门 | 28 级 | 3 级 | 14 | 平原 |
| 三打内院 | 30 级 | 4 级 | 18 | 平原 |

每次粮耗为 `8 + 向上取整(实际随行人数 / 2)`，独行消耗 8 粮。使用实际英雄、军令、兵种和部队，支持独行与带兵；连续出征可以先治疗伤兵、补员。出征准备可调整阵容，取消不扣费，确认出战才扣体力与粮草。失败或撤退不返还消耗，可重新整备后再战。

祝庄守卫和栾廷玉属步军，援骑和祝彪属骑军。栾廷玉、祝彪使用现有可打断的首领蓄势规则。等级是入场门槛，并不保证任意阵容必胜；弓军克制、治疗续航和控制打断都有价值。

战胜后需在当地确认战果。战斗结束但尚未领取、战中暂停、卷终等状态都可保存与继续。已经确认的任务不能重复打取或领取奖励。

## 卷终与后续

三打战胜并确认后，前往庄后粮仓清点与安置，才完成第五卷。卷终额外给予招贤令 4、登仙印 3、灵蕴 8；差事页另有四份对应主线酬劳。卷终后庄后粮仓每日可领取药草 2，按既有每日规则刷新。

第六卷《高唐救援》当前仅为卷末预告，尚未开放。

## 存档与发布

存档继续使用版本 2，通过已有地图访问、剧情步骤、标记、每日计数和战斗快照保存。旧英雄、品质、装备、营建和四卷进度保留。**无需新建数据库表或执行迁移 SQL。**

**云存档 Worker 必须更新到 0.23.0。** 新增地图、故事、敌人与首领规则随 Worker 打包。前端上传含第五卷内容的存档前，会检查 `/v1/game-version` 返回 `chapters >= 5`；旧 Worker 会得到升级提示，本机进度保留。

先在项目根目录部署 Worker，再推送 GitHub 发布前端：

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

本轮只完成本地开发和验证，尚未推送 GitHub、部署 Worker 或修改线上数据库、存档。
