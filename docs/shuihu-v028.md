# 白泽水浒 0.28.0 · 山河经营与分队远征

## 入口与本次范围

刷新新版后，从主导航「山河」选择「开启山河经营」。旧档原有六卷、112 位人物（108 正册与 4 位外传）、装备、进度和资源保留；开启不赠送资源、不追溯补发战果。好汉的新战法在「好汉 → 人物详情」查看。招贤、打造等原有直接入口继续可用。

本次实现八个方向的首版：三处商路经营、一支独立分队、36 天罡本领和行记、三类建筑分支、五段短程远征、军队老兵经验、三件军中藏品、专项试炼和云端分组演武。地区经营目前覆盖郓城、景阳与东溪；人物本领本轮覆盖 36 天罡，未声称 108 位均已有独立行记。老兵经验使用军队总池，不为每一名士兵建个人档案。

## 1. 商路和势力

三地分别对应郓城商会、山乡保甲、东溪船帮。聚义厅 1、2、3 级依次开放地区事务，每地每天受理一次，三类委托共用额度，开战即扣体力、粮草和次数。

- 护送粮队：体力 8，胜利治安 +5、补给 +15、关系 +8，粮草 45、碎银 80。
- 清剿路匪：体力 8，胜利治安 +20、补给 +5、关系 +3，木材 30、碎银 100。
- 商盟急托：关系 20 开放，体力 12，敌军强度为本地普通委托的 1.3 倍；胜利治安 +10、补给 +10、关系 +5，碎银 120、招贤残令 1、武学残页 3。

出征粮草为 5 加随军人数的一半向上取整。失利仅令本地治安下降 3，不发胜利物资。属性上限 100，无离线衰减。

互市每日每地一次，粮草产出为 40 加补给值的一半向下取整。价格原为碎银 180，关系 20 后 150。治安 80、关系 30 时可支付 300 缔盟，首次获得招贤令 1，以后该地互市价格 120。每地只缔盟一次。

## 2. 独立分队

聚义厅 2 级后，每日可派一支 1—3 位闲置好汉组成的分队，带兵 0—300 人，0 人为独行。主队、生产任职、据点守将及其他外派人员互斥，派出人员的装备、培养和阵容调整也受限制。士兵从主队可用兵力扣除，在外期间仍占兵营总容量。

分队护送需 10 分钟，成功获粮草 70、碎银 100；分队探路需 15 分钟，成功获木材 50、精铁 3。两者均消耗体力 10、粮草 10 加兵力一半向上取整。出发时按真实战斗引擎、当时阵容与训练分支自动演算，不自动用药；到时手动接回，结算阵亡、伤兵与所得。成功的参与英雄各获历练 200。刷新和离线不重复结算，也不会自动再次派出。

## 3. 天罡人物本领、行记与灵仙战法

36 天罡均有具名基础本领，包含怒气支援、首击提前、护阵，以及对首领、受控敌人、残血敌人、地形或战斗时机的条件增伤。开启山河经营后只影响新战局，凡品即可使用。

保留原有 6 位人物行记，补入其余 31 位天罡行记，总计 37 位可查看三段支线。这些文字为本作创作。原有任务条件保留，新增行记按本人等级、参战胜利、寨子规模、灵品要求推进。每段酬谢只选一次，使用原有招式书、信物和材料体系。

天罡达到灵品可在互斥战法中选择：破锋伤害 +4%、防御 −4%；守成防御 +8%、伤害 −4%。仙品分别强化为伤害 +8% 或防御 +14%，代价保留。每次调整消耗碎银 200、武学残页 3，不重算已开始的战斗。

## 4. 建筑分支

对应建筑达到 2 级后，每次改造消耗碎银 300、木材 40。同建筑只能选择一个分支。

| 建筑 | 分支一 | 分支二 |
| --- | --- | --- |
| 农田 | 稳产轮作：农田每批 +2，工坊 −1 | 集中垦殖：农田每批 +4，伐木 −2 |
| 兵营 | 新兵教场：募兵每人碎银 3 → 2，老兵属性增益减半 | 老兵整训：参战所得军队经验 +25% |
| 医馆 | 集中疗养：每次可治疗人数翻倍 | 随军救护：新战局阵亡比例乘 90%，减少部分转为伤兵 |

已产物资不会扣回。生产仍须开办原有经营拓土；分支影响之后的批次产出，不凭空领取一批物资。已出发分队的训练收益按出发快照结算，途中切换不改变它。

## 5. 五段短程远征

聚义厅 3 级开放，每日一次。启程消耗体力 20、粮草 20 加随军人数一半向上取整。启程后五段路线全部显示；前四段可选择战斗或随机营地、行商、行旅事件，第五段为首领战。

气血和真实兵损连续保留。营地恢复仍在阵英雄的 25% 气血，退阵者不会复活或在后续节点继续统兵。途中不能切换主队、经营、升级、募兵或改装备；须完成或撤回后再安排。战斗可暂停、保存与刷新接续。

每场战斗另付粮草 5 加实际随军人数五分之一向上取整。普通战胜暂存碎银 100、精铁 2，首领战胜暂存碎银 200、精铁 4。营地需粮草 15；行商需碎银 80，暂存布匹 3、武学残页 2；援助行旅需粮草 20，暂存碎银 50、武学残页 3。

战利品到回寨才入库。完成五段带回全部；提前撤回或战败带回暂存物资的一半，各项向下取整。已消耗体力和粮草不退，阵亡不会回滚。回寨英雄休整，士兵仍按实际伤亡处理。

## 6. 老兵经验

军队平均经验 = 总经验 / 在营士兵与伤兵人数，向下取整，最高 200。平均 40 为熟练兵，120 为精锐兵，实际统兵英雄在新战局获得攻击、防御 +5% / +10%。新兵不带经验，补员会稀释平均值；伤兵保留经验，阵亡按平均经验扣除。

每场胜利的非阵亡参战士兵各得 20 经验，失利为 5，老兵整训再乘 1.25。分队带走对应经验，返程才将存活兵员经验归还，不与主队共享同一批经验。独行不练军队，也不享受老兵增益。

## 7. 军中藏品

一次只能装备一件，效果影响后续新战局。来源明确，不增加随机付费抽取：

- 护运军旗：每完成 3 次商盟急托可领取一次；护送或水域战斗开场全队获得 8% 护阵，持续 12 秒。
- 奋威战鼓：每完成 5 次清剿路匪可领取一次；开场怒气 +8、防御 −4%。
- 识途铜盘：每完成一次完整短程远征可领取一次；远征战斗胜利后仍在阵英雄额外恢复 5% 气血。

首次领取入藏，后续重复领取转换为碎铁 3、武学残页 2；每个达成次数只能领取一次。藏品和物资获得均显示收获弹窗。

## 8. 专项试炼与分组演武

本机专项试炼分为独行、百人精兵、凡品聚义三组，每组固定五层。聚义厅 3 级开放，各组逐层通关，三组合计每日 3 次。每层体力 10，粮草 5 加兵力一半向上取整。各组每层首次胜利获得残页 2、灵蕴 1；第五层额外招贤令 1 和对应勋章。首胜奖励每存档仅一次，重复只更新更好的历史记录。分组条件不符时仍可进入出征准备，调整阵容后确认。

云端服务器演武在「存档」选择常规、独行、百人、凡品组；「历练」查看对应榜。独行不带兵，百人组实际随军 1—100 人，凡品组全队品质为凡。各组使用当期周本敌军，各自从第一层开始，成绩互不覆盖。服务器按上传阵容独立演算，不消耗资源、不发排行奖励。验证的是战斗计算，培养数据仍来自可导入的存档。

排行榜仅在云档已公开、且当前版本仍与该成绩参赛版本相同时展示参赛人物。私有档只展示编号、层数和成绩；更新存档后不会把新阵容冒充成旧成绩的参赛阵容。

## 存档兼容与发布

新增可选 realm 字段与对应战斗快照，旧档不强制开启。未开启的旧战局按原规则接续。外层存档版本仍为 2，名册版本仍为 5。

**需要更新 Worker；不需要更新数据库表。** 分组复用已有 verified_scores 表的 period 文本字段，常规组沿用原值，其他组附加组别后缀。已存在该表的数据库不必重复执行 0002_verified_ranking.sql。新 Worker 继续接受旧档，新前端遇到旧服务会在上传新字段或参加新分组前提示升级；旧页面不能静默删除已上传的山河进度。

本次只完成本地开发和验证，没有推送 GitHub、部署 Worker 或修改生产数据库。发布顺序：本地验证 → Worker → GitHub 前端。

在项目根目录中，每条命令单独执行，上一条成功再继续：

```bash
npm run test:all
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json

git status
git add public/game cloud/shuihu package.json docs/shuihu-v027.md docs/shuihu-v028.md scripts/shuihu-v027-selfcheck.mjs scripts/shuihu-v028-selfcheck.mjs
git diff --cached --stat
git commit -m "更新水浒 0.28：山河经营、分队远征与分组演武"
git pull --rebase origin main
git push origin main
```

如果缺依赖，先停止本项目开发服务，再执行 npm ci --include=dev；不要全局安装 TypeScript 代替项目依赖。若 rebase 报冲突，先解决冲突，不要强制推送。GitHub 推送后等待现有站点构建任务成功，再刷新线上页面。
