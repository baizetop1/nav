# 白泽水浒 · 郓城入卷（0.2.4）

这次是开场与初期叙事的增量改动，不扩充玩法版本、不重置进度、不改变战斗、招募或奖励规则。

## 首次开卷

无本机游戏存档时，先单独展示序章，不显示功能导航和资源面板：

> 宣和年间。  
> 山东郓城。  
> 江湖风云初起。  
> 你没有武艺。  
> 但你有识人之能。  
> 今日起：  
> 你便是白泽寨主。

文字依次轻显，约一秒半内展示完整；系统设置为减少动画时直接显示。无需等待动画，随时可点「踏入郓城县」。按钮支持键盘和触摸。

- 「踏入郓城县」后才开始保存。
- 「接续旧卷」进入导入/恢复界面，取消后可回卷首；在序章及其导入页停留、刷新时钟，不自动创建存档。
- 读取到有效存档时直接回到当前进度，不重复播放序章；旧版存档仍按既有规则升级并保留备份。
- 坏档保持在恢复界面，不通过开场按钮覆盖原文。另开新卷仍需明确输入确认语和二次确认。

## 先听城中事，再安排江湖行

| 郓城入口 | 实际地点 | 叙事与原有操作 |
| --- | --- | --- |
| 酒肆传闻 | 郓城酒肆 | 听东溪村、景阳冈与宋江的传闻，结识白胜与时迁，邀请白胜引路 |
| 县衙告示 | 郓城县衙 | 阅读虎患榜文，保留原有差事入口；到访按原规则计入主线条件 |
| 江湖消息 | 郓城城门 | 听行脚客说路，沿官道探访；东溪村仍须先到酒肆打听才解锁 |

每张入口卡带本地细线 SVG 小图标，整张可点击，不另设小点击点。

刚踏入郓城时不先显示资源数字和全套菜单：「行箧与其他安排」中可展开原七个功能；「城中去处」收纳铁匠铺、马厩、招贤馆；「驻足与寻访」保留寻访和等候。存档入口始终可达。

探访其他地点或已有相识、招募等进度后，正常显示功能导航。重回郓城仍保留三条故事入口，其他地点保持此前的聚焦布局。

郓城、酒肆、县衙的场景文字、酒肆三段传闻与宋江/时迁/白胜初见对白补充了叙事。传闻沿用原 action ID、解锁效果和仅可执行一次的限制，点击故事入口不自动发放奖励或招募好汉。存档格式仍为 version 2，资源版本号更新为 0.2.4。

## 验收

- `npm run test:shuihu-opening`：序章原文、页面隔离、真实出口、旧进度识别、渲染不改存档、传闻防重复和向导入队。
- `npm run verify`：生产构建和全部 29 组自检。
- 现代浏览器：首次/再次进入、键盘与小图标点击、折叠菜单、三条故事路线、旧存档导入取消/确认、坏档保护、存储满时临时游玩与导出。
- 桌面和 320/390/768px：无横向溢出，减弱动画、触摸跳转、折叠后功能可达；两卷剧情、招募弹窗、阵容与装备回归。

用户此前要求暂缓的旧手机 `structuredClone` 兼容问题没有在此版本处理，详见 [已知问题](shuihu-known-issues.md)。现代浏览器的手机尺寸检查不代表旧内核已修复。
