# 白泽水浒 · 已知问题

## 待修复：部分手机浏览器无法进行游戏操作

- 状态：用户明确要求后续再修，0.2 暂缓处理。
- 报错：`structuredClone is not defined`。
- 原因：`public/game/js/utils.js` 的状态复制直接依赖该浏览器 API；缺少它的浏览器环境在移动、战斗、刷新进度时会中断。
- 影响：页面能显示，但游戏操作和自动更新失败。旧内核仍不属于本版已通过的运行环境。
- 临时办法：使用支持该 API 的较新浏览器。不要为了处理此问题清除站点数据；已有进度先导出。
- 待办：增加状态复制兼容方案，覆盖没有该 API 时的移动、战斗、升级存档和导入导出；再检查同类 API 依赖。
- 验收要求：不能只用现代浏览器模拟手机尺寸，需要模拟缺失 API，并在受影响的实际手机浏览器复验。
