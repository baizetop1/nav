# 白泽水浒 · 兼容性记录

## 0.14.1 已修复：缺少 structuredClone 导致操作中断

旧手机浏览器缺少 `structuredClone` 时，过去会在移动、战斗和刷新进度时报错。本版增加游戏状态的深复制兼容实现，并让装备预览复用它。同时替换游戏中的 `Object.hasOwn` 和数组 `.at` 依赖，无须清除已有存档。

自动验证覆盖关闭以上接口后的数据载入、移动、养成、完整战斗、旧档升级、装备预览和文件导入导出；相同种子与操作的战斗结果和现代接口版本一致。浏览器验证使用隔离 Edge，主动移除接口并以手机尺寸操作。

受影响的真实手机尚未实机复验；不据此宣称支持所有旧内核。浏览器仍需要支持 ES 模块、可选链、IndexedDB 和原生 dialog 等现有基础能力。若更新后仍无法操作，应保留原档并记录具体浏览器及报错。
