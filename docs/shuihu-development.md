# 白泽水浒 0.6.0 · 寨务与战备

本轮把经营、英雄养成和出征搜获串成一条可重复游玩的路线。沿用深绿与金色界面、14 位人物像、原有江湖剧情和云存档入口。

## 经营与英雄

- 今日寨务有均衡、集中伐木、开仓备粮、赶集通商四种选择，每次消耗 5 体力。专项产出为基础值的 175%，其他两项减半；数值向下取整。页面在操作前显示实际产出。
- 好汉页可委派一位已入寨英雄为寨务主事，增加其擅长物资产出 20%，每次经营本人获得 25 历练；满级后不累积经验。可随时更换或卸任，主事仍可出征，不占用新的队伍位置。
- 擅长木材：武松、林冲、鲁智深、刘唐、杨志；擅长粮草：白胜、阮小七、公孙胜；擅长碎银：吴用、宋江、柴进、燕青、花荣、时迁。这是本游戏的经营分工。
- 人物卡新增经验进度条、距下一级所需经验、内务所长与委派按钮。收获弹窗同时显示实际增加的历练与等级变化。
- 建寨志提供五项一次性阶段酬劳：安居立业、初战扬名、寨中有序、粮道畅通、威震山林。已满足的设施与总出征胜利会承认旧进度；护粮和攻寨的独立胜利计数从此版开始。领取时原子写入标记，刷新、导入与云端接续不会再次发放已领酬劳。

## 出征与掉落

- 山林清剿使用稳扎稳打，额外攻击 +15%、防御 +10%。
- 护送粮队使用结阵固守，额外防御 +20%，伤兵计算比例乘 0.65。
- 攻打匪寨使用强攻破阵，额外攻击 +20%。强攻原有防御 -15% 与较高伤兵风险仍在。
- 地形加成乘在原军令和兵力增益之后，战斗开始即写入单位数值；不会仅修改提示文案。其他军令可以正常出征，不强制选推荐项。
- 寨务战、战斗副本和计策副本胜利结算时，各有 25% 概率获得一件装备，75% 没有装备，无保底。先判定掉落，再从对应品质池等概率取一件；可重复掉落。失败与撤退不抽取。
- 寨务三处分别掉凡品、良品、珍品。副本要求等级 1–14 对应凡品、15–29 良品、30 级及以上珍品；各入口可展开查看完整装备池。
- 装备达到 200 件时，命中的装备折为品质阶数 ×2 的碎铁，避免容量溢出或战果结算失败。装备、坐骑与其他掉落共用保存的 RNG，弹窗不再抽取。
- 坐骑契仍为每张独立 20% 概率、无保底，已持契或已领骑不重复产契。
- 战斗结算弹窗增加胜负、随行乡勇、安然归营与伤兵人数。撤退也显示收兵结果，关闭弹窗不改变战果。

## 存档与发布

存档主体版本仍为 2，camp 版本仍为 1。本次不新增存档顶层字段，主事和领取标记使用既有 progress.flags，分任务胜利数使用既有 stats；原云端投影保留这些字段。已用上一版本 Worker 的实际代码和内存 SQLite 验证新增进度的上传、下载、历史与回滚，无需迁移 D1。静态资源版本为 0.6.0。

游戏仍使用 https://save.baizeone.top，未更改 DNS、网关或生产存档。网站上线需要提交导航仓库并推送，等待 GitHub 部署。本轮不会自动发布。
