# 白泽水浒 0.40.0：接顺第一轮游玩

这是后续开发路线的第一项：让新玩家知道现在做什么、战斗中能改变什么，以及所得如何帮助下一次出征。后续人物差异、路线变化、经营联动和长期挑战尚未在本版完成。

## 本版完成

- 寨子首页按实际状态提示：伐木场、农田、兵营 → 领取安居立业酬劳 → 穿戴已有装备 → 培养主力 → 募兵或选择独行 → 首战。已经完成却没领的初战酬劳也会提示领取。
- 引导按钮直接进入对应功能。首战仍先显示出征预览，确认才扣资源；军令实操可跳过，不作为主线门槛。
- 寨子增加「军令实操」：固守接住攻击、带伤治疗、截断蓄势。借用林冲、白胜或王进教习，使用真实伤害、治疗、怒气和打断规则；操作达成即结束，不必击杀高血量对手。
- 演武默认暂停并使用手动招式，可以暂停观察后施招。普通战斗的暂停规则保持原样；个人保存的自动/手动模式不会被练习覆盖。
- 演武不扣体力、粮草、药物或兵员，不解锁教习人物，不计入真实胜负，也不覆盖最近实战复盘。退出、失败和反复练习不发资源；仅保存已经掌握的课程。
- 收获弹窗新增「成长变化」：显示实际等级、属性、统兵变化和新招式。新装备按当前队员装备提供穿戴收益参考，实际穿戴仍由玩家选择。
- 结算底部给出下一步与直达按钮。真实战败会结合伤兵、超时、施招情况引导医治、培养、练习或调整阵容。
- 手机继续使用紧凑布局和按钮分页；新增实操及结算不依赖纵向滚动。

招贤概率、坐骑掉率和既有资源奖励未提高。新档验证使用原有装备、经验丹与建寨目标酬劳：三个随机种子均可在不等待恢复、不补发资源的情况下，完成一次山林清剿后培养到游历门槛、升级聚义厅并开始首趟游历。这是可行路线验证，不代表所有阵容或任意操作都能获胜，也不代表已经证明长期留存改善。

## 存档与发布

旧本机存档直接接续。进行中的演武、蓄势剩余时间和课程完成情况可导出、导入并上传云端；重新打开战局仍先暂停。云端防止旧页面删除已完成课程。

需要先部署新版云存档 Worker，能力字段为 `openingLessons: 1`。**本版不修改数据库表，不运行 D1 迁移。** 尚未升级的云服务会拦下含演武进度的上传，本机进度保留。

Git Bash 中每行单独执行，先验证、更新 Worker，再上传前端：

```bash
cd /f/nav-main/nav-main
npm ci
npm run test:all
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
curl https://save.baizeone.top/v1/game-version
```

确认返回 `release: "0.40.0"` 和 `openingLessons: 1`，再执行：

```bash
git status
git add public/game cloud/shuihu package.json scripts docs
git diff --cached --stat
git commit -m "feat: connect opening progression and add practical battle lessons"
git pull --rebase origin main
git push origin main
```

暂存范围也会包括此前尚未提交的游戏改动，请检查清单。若 rebase 发生冲突，处理冲突后 `git add`、`git rebase --continue`，成功后再 push；不要强推。前端上线取决于现有部署流程。本次开发未执行提交、推送或远程部署。

## 验证

- `npm run test:shuihu-opening-flow`：三项真实操作、过早施招、退出与重复、物资和阵容隔离、存档恢复、非法存档、三份完整新档到首次游历、成长说明和失败建议、旧服务拦截。
- `npm run test:shuihu-opening-flow-cloud`：真实 Worker 搭配内存 SQLite，验证旧档、蓄势中、已获胜待结算和课程完成后的上传下载，拦截课程丢失与非法进度；不访问线上数据库。
- `npm run check:shuihu-opening-flow`：360 像素手机和 1440 像素桌面真实领取酬劳、结算跳转、经验丹预览与成长、固守/治疗/打断、暂停重载及完成记录保留。需要本地服务和 Playwright。
- `npm run check:shuihu-screen-pages`：四种手机视口、63 个页面以及翻页、表单、招贤和实时战斗交互。
- `npm run check:shuihu-journey-rewards`：路线目标、兑换、弹窗、穿戴比较、刷新保持。
- 完整自检与生产构建：`npm run test:all`、`npm run build`。
