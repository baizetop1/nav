## 抽取与养成

普通招贤卡池扩到 168 人：一星 38、二星 50、三星 46、四星 23、五星 11。仍先抽星级，再在同星级人物中等概率选择。

星级基础概率保持五星 1%、四星 6%、三星 23%、二星 45%、一星 25%；20/50/100 次星级保底与专属招贤规则不变。低星扩池会改变每个具体低星角色的概率，四五星名单没有改变。

散人首次抽中直接入寨，不需要提前相识；也可在名册达到经营条件后付银直接迎贤。重复散人仍给 3 枚对应信物和 15 功勋，3 枚信物可换专属招式书，荐贤积分照常累计。

48 位新人各有肖像、人物往事、四项招式、专属兵种和坐骑。进阶招式包括护众、救急、解困、护阵、打断、穿防、双目标控制、流血、协同护军、削弱、后排截击和追击等 12 种战斗机制。成长仍使用既有等级、招式、装备、坐骑及凡灵仙系统。

## 查找人物

好汉 → 好汉名册：星部选“江湖散人”，资质星级选一星、二星或三星。每星级 20 人，分两页；可叠加姓名、状态和所长筛选。翻页保留筛选，重置恢复全部人物。

## 存档与发布

名册版本由 6 升到 7。完整的旧 112 人、124 人存档均可迁移；旧人物、装备、资源、招募保障和散人养成保持，新增角色以未入寨状态补入。损坏或缺失旧人物的存档仍会拒绝读取，不会伪造修复。

**先更新 Worker，再发布前端。没有新数据库表，无须执行新的 SQL 迁移。** 新前端会阻止上传到不支持当前名册的旧 Worker；新 Worker 拒绝旧名册覆盖已升级的云档。

Git Bash 中逐条执行，每条成功后再执行下一条：

```bash
cd /f/nav-main/nav-main
npm run test:all
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json

git add -A
git commit -m "扩充六十位江湖散人 0.32.0"
git pull --rebase origin main
git push origin main
```

若 rebase 有冲突，先解决再推送。GitHub 推送后仍需要现有网站部署流程完成。
