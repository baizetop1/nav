# 游戏文案约定

## 按用途写

- 按钮用直接动作：出征、建造、领取、继续、返回。功能相同的按钮保持同名。
- 任务说明写清对象、地点和完成条件，使用已有数值与条件。
- 对白围绕当前情境：要去哪里、遇到什么麻烦、拿什么交换、打算怎么做。
- 旁白写看得见的动作和东西。人物性格由说话与行动表现，少用评价句。
- 地图描述控制在一两句，选该地点特有的细节。
- 人物简介说明来历或本事；对白另写，不重复简介。

## 编辑时核对

- 删去反复出现的江湖道理、劝勉、总结、空泛标题和刻意排比。
- 角色之间有口吻差别，普通人物可以只谈买卖、吃住、工具和路况。
- 规则说明与剧情正文分段；有必要的数值、限制和结算条件全部保留。
- 原始剧情文本末尾的规则说明用空行与全角括号单独分段，页面将其显示为小字。
- 文案改动只涉及展示字段，校对时确认 ID、条件、奖励和分支前后相同。
- 修改前后各看一次手机页面；文字变长时检查分页与按钮能否正常点击。
