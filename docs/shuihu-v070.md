# 0.70.0：荒祠地宫

开发日期：2026-10-10。本轮完成第三片固定探索地区。本地版本 0.70.0，尚未发布到 GitHub 或 Worker，未生成新 APK。

## 入口与流程

江湖 → 区域探索 → 荒祠地宫。寻宝副本和乐和的邀请页也有地图入口。

地图显示六处地点：荒祠山门、破殿前庭、残钟楼、回声夹道、残碑石室、地宫内室。所有地点和道路提前可见；未开放地点显示原因。地图保留位置、走过的路和人物事件，当前目标可直接跟进。

1. 到残钟楼结识乐和。
2. 清出破殿或夹道，再回钟楼听声辨路。发现东墙暗门后，山门与残碑石室直接相连。
3. 花粗布 2 拓写残碑，取得旧碑拓片 4。此后荒祠派遣每批拓片额外 +1，不追补此前暂存。
4. 破殿与夹道的寻常难度合计通关 5 次后，可进入内室。沿用原副本入口条件，没有额外增加次数。
5. 击败内室头目，收取一次性书箱（基础技能残页 2、武学残页 3），回钟楼交还谱册、邀请乐和。

书箱与邀请互不代领；若先邀请，地图仍会提醒收好书箱。已有乐和时保留等级、培养和信物，只完成委托。所有一次性材料、邀请与拓碑均防止重复领取。

## 战斗与产出

破殿有三名敌人，头目会蓄势护阵。夹道采用现有的“鸣钟援阵”：增援一名守卫，全敌气血 +15%、速度 +10%；头目蓄势 3 秒后给存活敌人各恢复 15% 气血。胜利必得粗布 2。

内室沿用蓄势治疗和两翼快攻。出征前显示敌人与应对提示，可保留打断招式、手动截招或集火头目。三处战斗均只由好汉出战，不耗体力、粮草、士兵；用药照常扣除。战后自动保存奖励，玩家选择继续探索或看战报。

其余装备、材料仍按原掉落表独立判定。普通战斗可能无掉落，未增加固定经验或碎银，未调整招贤概率。失败、撤退不发掉落、不完成地点战绩。

## 回寨与派遣

乐和入寨且客舍建成后：

- 荒祠派遣每批粗布额外 +1。
- 地区武学残页配方改为拓片 5、粗布 1、碎银 25，得到武学残页 2；原来需要拓片 6。
- 与普通“整理武学残页”共用每日 4 次额度，不额外增加加工次数。

残碑拓写的拓片加成不要求客舍。派遣仍每半小时一批、最多暂存八小时；顺路寻访仍四小时一枚乐和信物、最多暂存两枚。营建或委托只影响之后的采集，原暂存不会重算。

从荒祠回寨可直接看乐和和客舍；残碑页与完成后的地图目标可直接进入地区配方。同步修正带地区参数的回寨入口，避免看见上次选择的其他故人。

## 存档兼容与发布

主体存档版本仍为 2。新增可选记录 exploration.ruins，结构与芦苇泽一致；activeRegion 新增 ruins。旧矿洞与芦苇泽的位置、事件和待结算战斗保留。文件存档和本机存档包含新记录。

Worker 新增 ruinsExploration:1 能力；未升级时，客户端在上传荒祠进度前提示更新，不发送覆盖请求。Worker 阻止旧客户端删除荒祠记录、已访问地点或已完成事件。无需新增数据库表，也无需重跑 D1 迁移。

发布时先部署 Worker，再推送前端。检查 /v1/game-version 的 release 为 0.70.0、ruinsExploration 为 1。本轮只完成本地开发；发布和 APK 构建单独进行。Android 源码版本同步为 0.70.0 / versionCode 42，以保持打包脚本的版本校验。
