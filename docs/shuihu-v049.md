# 白泽水浒 0.49.0：商路行记与军需加工

## 商路行记

入口：更多 → 游历 → 商路行记。青石古道、芦荡渡口、断崖粮道各有三章；每章有两条处理办法和对应结局。聚义厅达到 2、3、4 级依次开放三章。

接下委托不扣物资。按章要求走通对应难度：接应路线需要途中护送一次行旅，清路路线需要击败一次强敌辎重。委托绑定接取后的新行程，旧通关不抵扣；失败、提前收队仍保留委托。完成后回行记付营建材料，工程和酬劳只结算一次。

- 接应工程：本路每场胜利后，在阵好汉额外恢复 3% 气血，每路最多 9%。
- 哨所工程：本路每场开战，在阵好汉额外获得 5 怒气，每路最多 15。
- 三章之后开放本路八阶巡守。急袭、坚垒、耗战三种规则轮换；界面列出气血、攻击、防御总倍率。仍需选择路线、战法、备战及契约。
- 巡守走通必得原绝险路契 4，另加 ceil(阶次 / 2)，即每趟合计 5–8。各阶首通另有材料自选匣，第 4、8 阶有招贤令，第 8 阶有登仙印。重打不重复发首奖。
- 每路专属装备图谱可淬炼三次，分别需要巡守 2、4、6 阶以及路契 12、24、40，另付精铁与碎银。全部同型装备的属性提高 15% / 30% / 45%；普通强化和开战特效保持原规则。

完整通路的原随机掉落仍按 35%、20%、8% 独立判定，不替代必得物资。普通招贤概率未修改。九章剧情与八阶巡守是有限内容；巡守可重打获取物资，但不会无限生成新剧情。

## 行囊与制作

新增 4 种材料、3 种药品、6 件装备，物品字典为 669 项、装备 29 件。行囊 → 军需加工按材料、药品、行路补给、原料分开。

| 内容 | 来源与用途 |
| --- | --- |
| 淬炼钢 | 碎铁、精铁加工；用于守路长枪、护额铁盔 |
| 密织麻布 | 粗布加工；用于短褐、束带、绑腿、药囊和盔内衬 |
| 鞣制硬革 | 熟皮、虎皮加工；用于短褐、束带和绑腿 |
| 浓制药引 | 药草、虎骨加工；用于三种药品与行医药囊 |
| 金疮膏 | 恢复受伤同伴 900 气血 |
| 醒神散 | 解除在阵同伴负面状态，并恢复 240 气血 |
| 壮骨汤 | 给怒气最低的在阵同伴恢复 25 怒气、360 气血 |
| 新装备 | 守路长枪、护额铁盔、斥候短褐、稳步束带、涉水绑腿、行医药囊，覆盖六槽位 |

新配方在对应集市或医馆 2 级学习，每份配方学习费 60 银。四种材料各限每日加工 8 份，三种药各限 3 份。原料可从已有副本和采买取得；加工页提供缺料采购入口。新药不能直接购买，与原有药共用 3 秒冷却，不能复活；满状态、全队满怒或没有负面状态等不适用情形不会扣药。装备属性、制作费用、实际用药目标均在界面说明。

## 存档与发布

兼容旧本机存档；行记进度为可选新增字段。新增材料、配方、装备和在途巡守支持保存、导出、恢复。云端增加 chronicleRoutes 和 workshopSupplies 能力标记；旧 Worker 会在上传前被提示更新，本机进度保留。

先更新云存档 Worker，再发布前端。数据库不需要迁移，不需要重复执行已有 SQL。

在仓库根目录执行：

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
npm run build
```

然后按项目现有 GitHub / Pages 发布流程上传前端。此次开发未执行提交、推送或云端部署。
