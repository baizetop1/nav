# 白泽水浒 0.3.2 · 手动 / 自动技能

> 0.4.0 已增加全部 14 人的招式成长与坐骑羁绊。新战斗自动模式优先可用进阶招，再选基础招；基础调息 5 秒、进阶 7 秒。公孙胜净化可以在同伴满血但有负面状态时使用，鲁智深护众无需先受伤。以下为 0.3.2 历史说明，新机制以[全人物养成](shuihu-growth.md)为准。

## 如何使用

进入交战后，在暂停/撤退栏下方的“技能释放”选择：

- **手动技能**：默认模式。双方持续普攻，我方主动技能由你点击。
- **自动技能**：我方在怒气足够、人物调息结束、存活且未受眩晕限制时，自动释放可用主动技能。治疗技能只在有存活同伴受伤时使用。被动技能不作为主动技能释放。

自动模式仍允许手动抢先释放；手动和自动使用同一套怒气、目标与人物冷却校验。切换模式不重置怒气、技能调息或药物间隔，不会自动使用金创药、回气散、解毒丹。

选择保存在当前游戏存档中，后续交战沿用。其他编号存档独立选择，另开新卷默认手动。

## 暂停与安全边界

- 暂停期间可以修改选择，但不会释放技能。接续/导入战局后仍然先暂停，需要点“继续交战”。
- 切后台、离开战斗页和浏览器长时间中断后，沿用原有暂停规则，不补算离线技能或普攻。
- 存档冲突时停止交战和模式修改。存储失败沿用未保存提示与导出保护。
- 胜负已定时禁用模式切换，不自动结算奖励，也不自动开启下一场。
- 自动施招在固定江湖日志中增加 `【自动技能】` 标识，之后仍显示原技能的实际伤害、治疗或状态结果。
- 不改招式倍率、概率、剧情、招贤或装备。本版也不包含待开发的坐骑、专属被动与技能升级。

## 实施规则

- 使用存档可选字段 `battleSkillMode: manual | auto`，新档默认 `manual`，旧档缺少字段按手动解释。存档版本仍为 2，不为补齐此字段重置进度。
- 自动决策使用引擎的有效交战时间，不增加独立的界面自动点击定时器。推进开始时检查已有可用技能，随后在状态、攻击和技能冷却事件处重新检查。
- 同一时刻先结算状态/到期、再结算按原速度顺序到期的普攻，最后按出阵顺序选择招式；每人按其技能列表选择第一个可用主动技能。人物施招后调息 5 秒。这个版本不是可编辑的战术优先级系统。
- 定时切片大小不影响自动决策、随机状态或战果；同一人物的技能不会因界面刷新多次施放。
- 导入导出投影和 Worker 快照校验同步支持该字段。如果已单独部署旧版云端 Worker，需要发布对应的新版 Worker 才能完整保留此选择；旧 Worker 的字段过滤可能将其丢弃。本次没有自动部署云端服务。
- 保留 0.3.1 的固定一屏布局。极矮视口下战斗操作栏随主功能滚动，避免覆盖技能模式按钮；日志区域仍不移动。

## 验证

- 新增 `npm run test:shuihu-skill-mode`：默认/旧档兼容、自动判定、冷却精确时点、眩晕结束、治疗、低怒气/退阵限制、手动抢先、模式切换、确定性、胜负停止、奖励防重复、无自动药物和存档导出往返。
- 云端 Worker + SQLite 测试使用自动模式快照往返，并拒绝非法模式值。
- 浏览器覆盖电脑和手机尺寸下的模式切换、触摸施招、暂停/接续、后台、文件导出、固定日志与极矮屏点击。
