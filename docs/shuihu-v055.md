# 0.55.0：材料加工与新式兵甲

本轮完成后续开发清单的第一项。新增六件可打造装备，两套装备在同一人的兵器、衣甲、饰品位置生效，可以混搭。

| 套装 | 装备 | 两件 | 三件 |
| --- | --- | --- | --- |
| 拒马装 | 拒马枪、叠片甲、包铁护心镜 | 防御 +8% | 再加气血 +10% |
| 轻袭装 | 雁翎短刀、窄袖行衣、行军筹牌 | 速度 +8% | 再加攻击 +8% |

拒马装偏承伤，轻袭装偏快攻。六件装备均为珍品，按现有规则强化和分解。套装加成计入穿戴对比与实际战斗，不额外增加开场触发效果。路线兑换装备和已有四套装备保留。

## 获得与消耗

- 打造入口：打造 → 打造购买 → 新式兵甲。基础装备在另一分类。
- 聚义厅 3 级、集市 2 级可打造；每件消耗碎银 240、一张兵器图纸和页面列出的材料。图纸按件消耗，不是永久解锁。
- 玄铁：集市 2 级学习精炼配方。每份消耗 70 银、淬炼钢 2、精铁 3，每日最多 4 份。
- 兵器图纸：集市 2 级学习抄制配方。每份消耗 60 银、粗布 2、行囊木材 1、精铁 1，每日最多 2 份。
- 基础技能残页：3 张加 20 银可整理为武学残页 1 张，每日最多 4 次，供后续抄录人物招式书。
- 三种配方各花 60 银学习。原有玄铁、图纸、基础技能残页的采买价格不变，也可在加工页的原料分类采买。
- 旧矿洞增加玄铁 4%、图纸 2.5%；荒祠地宫增加图纸 2.5%、基础技能残页 6%。这是寻常档概率，险境、深处沿用 1.3、1.6 倍。各条独立判定，仍可能空手。原有条目的概率不变，特殊副本共有 46 种不同掉落。
- 新兵甲不能以零价格购买，也不直接加入随机装备掉落表。

配方显示持有量与需求量，缺料可跳到相应加工配方或对应副本掉落表页。手机继续按屏翻页；材料入口和分类不增加长列表滚动。

## 存档和发布

旧存档不需要重开。新增装备复用原装备记录，新配方复用原军需记录，没有新数据库表，不执行迁移 SQL。

先更新 Worker，再发布网站。能力接口 `/v1/game-version` 应返回 `release: 0.55.0`、`forgeExpansion: 1`。前端会阻止把新装备、已学配方、新材料掉落战果上传给旧 Worker；新 Worker 拒绝普通上传抹去已学的新配方。需要回到历史版本时走历史回滚。

本轮没有自动推送 GitHub、部署线上或更新 APK。旧 APK 不包含此次改动。

在项目根目录逐条执行，上一条成功再执行下一条：

```bash
npm run test:game
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
git status
git add .
git commit -m "补齐材料加工和两套新式兵甲"
git pull --rebase origin main
git push origin main
```
