# 0.68.0：探索事件、试阵与连续挑战

这一轮继续完善已有入口，不新增一套独立大厅。招贤概率、特殊副本原有掉落表和物品价格不变。0.67.0 的内容一起保留；本轮尚未提交、推送或部署。

## 探索与同行人物

特殊副本的三段探索现在使用矿洞、芦荡、旧营各自的事件池，共九个事件。每趟抽取两个不重复的区域事件，开始时即保存在存档中，刷新不重抽。旧版已经开始的探索沿用原选路，收队后新开一趟才使用事件池。

选择前显示增援、敌军强化、毒伤等风险及额外材料。绕行恢复存活好汉的气血，其他选择按路线提供原有材料，不改变基础随机掉落。

八位人物参与部分事件：时迁、乐和可以降低相应遭遇的敌军攻击，宋清、白胜、项充可在对应事件恢复队伍气血，汤隆可解除炉房开场护阵，阮小七、安道全可避开毒滩的开场中毒。帮助只在本人随行且尚未退阵时生效，不要求玩家必须带某人，也不能复活退阵者。

入口：副本 → 特殊副本 → 矿洞 / 芦荡 / 旧营 → 三段探索。

## 同条件试阵

演武页和装备穿戴对比页都有“同条件试阵”。使用实际战斗逻辑，对照当前与换装后的取胜结果、耗时、伤害、有效治疗、承伤、存活、剩余气血和装备 / 任务本领触发次数。

试阵使用自己的出阵队伍、固定随机种子、自动施招，不带兵、不用药；可选矿洞护阵、芦荡毒蛇或旧营快攻，难度沿用已有解锁条件。换装比较要求穿戴人已经编入队伍。只在副本中计算，不扣玩家物资、不写战绩、不改变真实掉落随机数。

试阵结论只适用于所选敌情；同一种子保证可重复，不代表两种配装的随机调用次数和每次暴击完全相同。

## 刷取记录与整理

装备目标及掉落表显示：记录以来有效刷取场数、出现该装备的场数、连续未得场数。只统计包含该装备掉落判定且已胜利结算的场次，退败不算。旧战绩不补算，没有额外保底，也不随记录更改概率。

“整理普通重复装备”先预览件数与所得碎铁，再确认分解。每种至少留一件；已穿戴、锁定、强化、精修以及精品以上装备均保留。采用原分解规则，预览后装备发生变化会拒绝执行；重复点击不重复兑换。

## 组合回顾挑战

十二卷通关后，战役回顾的实战难度新增：

- 援兵夹击：开场用骑兵补足五名敌人，原敌军气血增加 15%；全员存活取胜才达成。
- 残阵突围：队伍以 60% 气血入场，首波敌军攻击增加 15%；胜利时全员气血至少为 40%。

规则在出战前可查看。后续波次保留原战役配置，记录完成次数和最快时间，不额外发资源、不改正式剧情。挑战选择改为下拉，避免手机上增加一排排按钮。

## 连续挑战

入口：特殊副本 → 连续挑战与整理。先手动通关所选难度，然后选择 2、5 或 10 场及金创药保留数量。确认后改为自动施招，每场胜利完成真实掉落与存档写入，再决定是否继续。不会自动使用药品。

遇到以下情况停止：达到约定场数、珍稀掉落、战败或撤退、装备接近满格、药品低于保留数量、其他入场条件不足、保存异常、离开游戏页、切到后台或刷新。珍稀掉落指精品以上装备，以及招募令、灵蕴、登仙印、兵器图纸、驯骑凭记。按钮“本场后停”取消后续场次，保留当前战斗。

连续计划只在当前页面有效，不做离线补刷；刷新后已保存的当前战局按原流程手动继续。三段探索需要本人选路，不参加连续挑战。

## 开局和回访

检查正常开局、模拟经过 20 分钟、隔天回访与实际战败后的提示，未给正常开局注入资源或等级。发现体力不足时缺少其他活动入口，现已在满足入场条件时提供“不耗体力寻宝”。战败后回到寨子，前期首页优先提示医治、配阵或招式练习，后期仍保持主线优先，同时保留调整入口。

这是脚本推进和浏览器操作检查，未进行真实玩家留存试验；20 分钟指模拟经过时间，不等同于一位新玩家实际操作 20 分钟。
