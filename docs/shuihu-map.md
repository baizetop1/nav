# 白泽水浒 0.7.0 · 江湖全图与常用功能直达

江湖页首先呈现文字全图，46 个地点按区域展示。地点名、实际相连出口、条件、可遇人物、副本与探访好处均能提前看到，包括原来的隐藏路线。地图可见不等于已经解锁：剧情、道具、夜间通行等条件仍然决定能否行路。

## 地图与行程

- 选择地点不会移动人物或改变存档；上方显示地点介绍、从当前位置出发的完整路线和未满足条件。
- 对已通行的路径可选择“沿路前往”，逐段调用原有移动规则。每段仍推进游戏内半个时辰，记录沿途初访；沿途不自动触发剧情、战斗、领取奖励或人物对话。
- 寻路考虑每段路带来的时间变化，不能在天亮之后走夜间密道；不通过反复绕圈替玩家等待。出发时重新计算与验证路径，失败整次操作不改变进度。
- 到达后可直接点“查看此地事务”，跳过全图进入原有场景。区域按钮可以跳到指定地区，手机端地图按单列排布。

## 常用功能直接访问

- 主导航新增“打造”，在任何地点可打造、购买、强化和分解装备。
- 招贤、行囊采买、好汉切磋、持契领骑取消地理位置限制，使用后不改变探索位置。
- 仍保留费用、材料、招贤令、人物相识、等级、强化解锁、每日次数和战斗期间不可操作的限制。
- 地图中的旧人物故事、传闻、地图解锁与风雪淬炼请教继续保留。
