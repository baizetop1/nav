# 0.36.0 · 专属实战与低星组合

本轮扩展游戏玩法，未构建 APK。已有网页、手机分页和全部旧存档继续使用。

## 怎么玩

在「好汉 → 人物任务」选择人物，可直接准备专属任务；也可在「山河 → 军需与战役」查看任务名录。尚未开启山河时，人物任务提供开启按钮。人物本人 10 级、聚义厅 2 级开放；出征准备可调整阵容、兵力与军令，取消不扣费。

九项任务共用每日三次尝试；每次消耗体力 10、粮草 5 加随军人数的一半向上取整。确认出发就扣费和次数，失败、撤退不返还。真实兵损沿用原规则。

每项首次达标另得本人招式书 2、灵蕴 2；不能重复领奖。林冲、花荣和阮小七原任务及强化保留。白胜、安道全、鲁智深三项的敌军属性在本人超过 15 级后按 `本人等级 / 15` 增强，避免后期秒杀使治疗、承伤目标失去可完成性；奖励不增长。其余任务保持固定敌军。

治疗目标使用真实有效治疗，不含满血溢出或药品。朱贵的禁药目标同时统计回气散、解毒药、回血药；不能靠不回血的药绕过。可以使用治疗招式和组合恢复。招式治疗强化不放大药品与固定比例组合恢复。

预览显示目标和收益，战斗中显示实际治疗、承伤、用药与施招进度，失败列出未满足条件。梁山志的战后复盘也能查看本战目标。

## 两组新组合

- **乡路互助（白胜、时迁）**：成员共同获胜三场解锁。两人存活、无眩晕、怒气各有 20，且存活队友气血不超过 70% 时，给气血比例最低者恢复 8% 最大气血。
- **响箭夜行（朱贵、时迁）**：同样共同获胜三场解锁。两人存活、无眩晕、怒气各有 20，且有后位敌人存活时，合击最后一位存活敌人并削去最多 10 怒气。伤害沿用既有合击公式。

每组每战最多两次，间隔至少 15 秒。触发时每名成员实际扣怒气 20，会影响个人招式时机；恢复和伤害均记入战报，并按成员均分贡献。原有三组组合保持规则。

## 存档与发布

本地文件、浏览器和云档保存新任务、组合进度及用药次数。旧战局没有用药次数字段仍可读；新禁药任务必须保留该记录。上传前检查云端 `personalTrials: 2` 能力；旧 Worker 会阻止上传新任务或新组合进度，并明确提示升级。本机进度保留，可先导出 JSON。

**需要部署 Worker，不需要数据库迁移或新增表。** 云端也防止旧页面覆盖已完成的新专属任务及降低新组合熟练度。这里没有替用户部署或推送。

顺序：先运行测试并部署 Worker，再提交发布网页。项目根目录：

```bash
npm run test:all
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

本版本没有重新构建 APK，也未修改 Android 版本号。旧 APK 不会自动包含新增玩法。
