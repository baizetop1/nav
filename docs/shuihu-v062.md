# 0.62.0 东溪聚义与黄泥冈取纲

## 内容

新增东溪村庄院与黄泥冈松林两张原创插画，复用于东溪村、晁盖庄、溪边渡口、庄后客舍，以及黄泥冈口、黄泥冈松岗、松林阴处、卖酒小径八处。加上 0.61.0，场景页共覆盖十九个地点；这不是十九张独立插画，也尚未覆盖十二卷。

七星聚义场景保留原有全文和选择，按实际步骤显示晁盖、阮小七与吴用的头像。聚义前、聚义后、取纲后分别显示对应描述。原有晁盖外传也可从村口接取，未达到建筑条件时，禁用的选择旁直接显示缺少的条件。

抵达松岗后，可直接“商议取纲计策”。进行中的计策显示场景图、当前安排次数、军汉与杨志的反应、最近一次行动结果。完整经过收在折叠项中。成功、失败分别有正确提示；失败结算后可以重新安排。

本次只接入表现与入口，沿用实际剧情条件、行路、计策数值和奖励。查看场景、切换标签不会产生奖励或修改进度。没有修改招募概率或战斗平衡。

## 存档和发布

场景从原有旗标与剧情步骤推导，计策仍保存原有 scheme 对象。刷新后继续当前安排，无新增存档字段、数据库表或 SQL 迁移。此次单独不要求更新 Worker；早期版本尚未部署的服务端改动，仍需按对应升级说明处理。

静态发布需包含 public/game 下新增脚本、样式及两张 WebP。图片合计 816242 字节，按当前场景加载。生成方式、原图路径及完整提示词见 `public/game/art/scenes/README.md`。
