# 主线与新手入口调整

## 行为

- 寨子首页从第一卷起优先显示当前主线、地点与下一步按钮，继续使用 `storyObjective` 和 `ui_storyResume`，不另外保存任务进度。
- 新存档的首页常用入口为采集物资、好汉、招贤。完成打虎、聚义厅达到 2 级或已有寨务出征记录，追加营建、募兵医治、打造。其他功能仍可经更多菜单或全部寨务进入。
- 采集物资在首页、更多的寨务分类、寨务选择器中使用同一名称。每次 5 体力，直接显示实际木粮银产出；主事说明折叠。沿用原有产出与存档规则。
- 演武列出已完成数量，已学会的课程明确标为已完成，按钮改为再次练习；练习后可直接继续主线。
- 战败建议只推荐未完成的治疗或打断课程。演武继续保持不改动资源、正式战报、原阵容的规则。

- `npm run check:shuihu-onboarding`：320×568、360×640、390×844、1440×1000；首屏主线、实际地点跳转、采集扣费及所得、刷新保留、更多菜单、旧存档入口和已完成课程推荐。
- `npm run check:shuihu-opening-flow`：实际固守、治疗、打断；中途刷新；完成记录和继续主线。

- `npm run test:game`、`npm run build`。
- 浏览器检查需设置 `SHUIHU_PLAYWRIGHT_PATH`（或已安装 Playwright）并启动本地服务。

本轮是前端引导调整，不新增存档字段，不需要 Worker 或数据库迁移。网页源码修改不会自动进入已经生成的 APK，发布 APK 时需重新构建。

## 操作指引补充

- 新手默认显示当前步骤的简短提示，金边标记对应操作；定位按钮只打开所在折叠区并跳到按钮所在页，不执行指令。
- 提示根据真实剧情、地点、战斗和演武状态重新计算。打虎路线覆盖前往客店、交谈、脚印、虎踪、交战、战后对话，并衔接后续主线。刷新或改走其他地点不会重置剧情。
- 解释自动普攻与施招方式的区别。是否切换自动技能仍由玩家点击决定，不自动用药。
- 采集、营建、募兵、升级、补给等页面补充操作和扣费提示。
- 可随时收起或开启。偏好按本机存档编号和开局时间隔离；已有较多进度的存档默认收起，可手动开启。该显示偏好不随云存档同步，游戏进度仍正常同步。
- `npm run check:shuihu-guidance` 验证金边定位、真实主线推进与战斗、脚印后的刷新衔接、收起/开启、老存档不改动。


## 粮路战役：寨主玩法试做

入口：寨子总览的“查看粮路”，或寨务功能切换中的“粮路战役”。这是一段可独立审查的短战役，检验“寨中问题 → 好汉准备 → 出征 → 伤亡与物资结算 → 长期经营结果”的玩法方向；尚未重构十二卷主线。

- 护送：体力 6，基础粮耗 6。保护粮车，完整度归零失败；胜利粮草 90–180，之后每日 24。固守可减轻货物受损。
- 侦察剿匪：先派人在寨好汉探路，再出征。普通好汉探路体力 4，白胜、时迁、戴宗、解珍、解宝体力 2，并使敌军额外削弱 15%。战斗体力 6，基础粮耗 8；胜利粮草 210，之后每日 18。
- 强攻：体力 6，基础粮耗 10；敌军较强，前 15 秒普攻伤害降低 35%，招式不受限。胜利粮草 260，之后每日 12。
- 三条路战斗粮耗均另加随军人数 / 4 向上取整。使用现有兵损、技能和战报规则；失败可改走其他路线，侦察保留，物资和兵损不返还。缺兵可独行。
- 胜利只能结算一次，之后可以付木材 30、碎银 60，在粮仓（每日供粮 +12）与救护站（每日最多 5 名伤兵归队）中选一项。永久保留本战役选择，不改变现有医馆和农田。
- 每满 24 小时收一批，最多积存三批。常规领取保留不足一天的计时；营建先结清已满天数，再重新计时。所有收入均在玩家点击时结算。

保存：新增可选 grainRoad 字段，旧存档没有该字段仍正常读取。前端与 Worker 同步更新，Worker 能力 grainRoad:1；不需要 D1 迁移。旧 Worker 上传保护会保留本机进度并提示先更新服务。旧页面不可覆盖云端较新的战役或营建记录。

验证：test:shuihu-grain-road、test:shuihu-grain-road-cloud、check:shuihu-grain-road。含三路线真实战斗、阵亡与换路恢复、预览取消、战中导出导入、重复结算拦截、两类营建、三天上限、领取计时余数、云端往返与降级保护，另验证 320/390/1440 宽度的交互。
