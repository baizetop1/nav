# 白泽水浒 0.29.2 · 好汉、山河、行囊分区

继江湖分区之后，本次完成三个主要页面的导航整理。每次只渲染当前分区，不把所有功能连续堆放在同一个长页面。

| 页面 | 分区 |
| --- | --- |
| 好汉 | 好汉名册、出阵阵容、人物培养、人物任务 |
| 山河 | 商路势力、分队远征、设施军备、寨防战役、专项试炼 |
| 行囊 | 随身补给、养成材料、装备整理、军需加工、随时采买 |

## 好汉

默认进入点将录。选人后可以直接打开此人的培养或人物任务；培养与任务分区中可通过选择框切换人物。培养包括经验、品阶、专属兵种、招式、坐骑与原有养成入口，人物任务包括行记与已实现的专属实战。

未入寨好汉仍可从名册查看本领、兵种及养成条件；预览不会允许绕过入寨条件实际培养。阵容编排和预设独立在出阵阵容中。

寨子中的培养待办、行记待办、材料追踪均跳到相应分区与人物。专属实战结束后回到该人物的任务分区。

## 山河

商路委托、互市、盟约与每月势力抉择放在商路势力；独立分队与五段远征放在分队远征；建筑分支、老兵与藏品放在设施军备；组合技与寨防接力放在寨防战役；分组挑战放在专项试炼。

正在进行的远征或寨防接力优先显示接续面板，避免在分区切换或刷新后藏起下一步操作。原有进度、战斗条件、花费与奖励保持不变。

## 行囊

体力补给与战斗药品在随身补给；招贤、培养道具和原料在养成材料；穿戴、锁定、筛选与对比在装备整理；加工配方和材料合成在军需加工；单件与批量购买在随时采买。

材料卡片的「查看加工配方」可直接切换加工页面；烟幕包可直接进入山河战役配置；人物培养道具可直接进入人物培养。顶部「补充体力」始终打开随身补给，避免停留在上次的装备或材料页。

## 界面行为与发布

分区按钮在内容滚动时保持可用；手机可横向滑动分区栏。切换分区回到顶部，只改变界面，不写入存档、移动角色或消耗资源。同一次打开游戏期间记住分区与已选人物，重新载入存档恢复默认分区。

本次为前端更新，不新增数据库表，不改云存档协议。若此前 0.29.0 云端协作尚未发布，其迁移与 Worker 升级仍按 shuihu-v029.md 执行。

代码尚未自动提交、推送或部署。
