# 白泽水浒 0.10.0 · 一将一部

本轮补齐 108 将专属部队、三套阵容预设、灵仙变招、装备套装、材料目标和每日小结；最后 62 位立绘已补全，108 将全部有对应图片。

## 在哪里玩

- **寨子 → 点将出征**：看每位将领本部兵力；可记录三套阵容。先保存英雄/军令配置，再保存预设；启用时同时替换英雄顺序、带兵/独行、军令和出征人数。
- **好汉或招贤 → 点将录 → 人物详情**：查看部队、训练至三阶、追踪练兵/升品材料。升品与练兵都有结果弹窗。
- **打造 → 套装搭配**：四套、每套三件；两件起效，三件追加。碎铁 5 + 碎银 20 可以重熔为精铁 2。
- **寨子 / 好汉 / 打造 / 历练**：显示当前材料目标，列出缺口、每日开放日期和其他来源。升品和练兵目标自动跟进下一阶；打造目标可手动取消。
- **寨子 → 每日小结**：按北京时间记录最近两个有操作日期的资源收支、胜败与招贤次数。按单次操作净变化统计，读取存档不增加收获。不会追溯更新前的历史。

## 专属部队

108 将各有唯一名称的部队，按人物专长分为步军、弓军、骑军，使用六种部队战法。名称和战法属于本作玩法设定，并非原著军事编制考据。乡勇仍共用寨子兵额；每次实际出征人数在最多三名英雄间按顺序均分，余数优先给前位，如 10 人 → 4 / 3 / 3。不足一人的部队不生效。独行继续使用英雄专长。

步军克弓军、弓军克骑军、骑军克步军，优势伤害 ×1.2、劣势 ×0.85；现在对每一名攻击者和目标分别判断，不再把全队强行改为同一兵种。敌情预览逐将展示克制。部队三阶的效果如下：

| 战法 | 效果 |
| --- | --- |
| 冲阵 | 随行时伤害 +4% / 8% / 12%。 |
| 坚壁 | 随行时防御 +6% / 12% / 18%。 |
| 齐射 | 随行时对满半血敌人伤害 +5% / 10% / 15%。 |
| 疾行 | 随行时速度 +5% / 10% / 15%。 |
| 水战 | 随行参与水泊争锋时伤害 +8% / 16% / 24%。 |
| 救护 | 随行时自身气血 +6% / 12% / 18%。 |

入寨即可统领一阶部队。升二阶需要聚义厅 2、兵营 1，消耗碎银 300、精铁 4、粗布 3、碎铁 5、武学残页 2；升三阶需要聚义厅 3、兵营 2，材料翻倍。练兵必成，不能在战斗或际遇中进行。兵力与伤兵沿用原有招募、出征、治疗流程，不额外生成隐藏兵额。

## 灵、仙变招

保留原升品属性收益。解锁人物进阶招式后，建寨后的非剧情战额外触发下列效果；全部 108 将按各自角色定位使用。基础招式与普通攻击不触发。已有招式名称、经验、装备、坐骑、羁绊均继承。

| 定位 | 灵品 | 仙品 |
| --- | --- | --- |
| 先锋 | 当前前位敌人流血 4 秒 | 流血 6 秒 |
| 护阵 | 最低血量同伴护阵 15%，4 秒 | 全队护阵 25%，4 秒 |
| 游击 | 追射最低血量敌人，35% 攻击倍率 | 70% 攻击倍率 |
| 谋士 | 前一敌人怒气 -10 | 前两敌人各 -15 |
| 辅佐 | 最低血量同伴清除一项负面，回复最大气血 5% | 回复 10%，同样清除一项 |

## 存档与上线

新增可选字段 development（版本 1），包含专属兵阶、三套预设、目标和最多两天的小结。旧存档直接读取，新字段在第一次操作时创建。旧的进行中战斗保留其 martial=1 或未标版本的规则；新战斗使用 martial=2，并保存各部人数、兵种、兵阶以及人物品阶快照。导入、导出、云端均保留这些字段；非法兵力合计、兵阶、预设或材料目标会被拒绝。

**先升级云存档 Worker，再发布前端。** 新前端上传前检查 /v1/game-version 的 development=1；旧服务不会接收并悄悄丢掉新进度。新服务也拒绝旧页面覆盖已有 development 的存档。无需更改域名、DNS 或 D1 表结构。

在原项目根目录运行：

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

随后按原 GitHub 发布流程提交前端文件。此次开发仅同步本机代码，不自动部署云端或推送 GitHub。周本榜继续是上传存档进度榜，没有服务端战斗重放验证，也没有排名奖励；本轮没有将其宣称为防作弊竞技榜。新增 94 将的独立长篇剧情仍不在本轮内容范围，人物介绍、招式、立绘、坐骑与专属部队已全覆盖。
