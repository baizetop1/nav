# 0.71.0：青石古道

开发日期：2026-10-10。第四片固定探索地区，接在旧矿洞、芦苇泽、荒祠地宫之后。本地待审查，尚未推送 GitHub、部署 Worker 或生成新 APK。0.70.0 的荒祠内容一并保留在当前代码中。

## 地图与时迁委托

入口：江湖 → 区域探索 → 青石古道。时迁邀请页、江湖游历的古道路线、寻宝副本与未解锁的古道派遣页也可直达。

六处地点从一开始就可查看：古道茶棚、运货岔路、松林哨台、老藤坡、林后小径、藏货营地。地点展示敌情、主要掉落和开路条件，位置与发现随存档保存。

1. 到茶棚结识时迁。
2. 打通运货岔路，或挑战有增援的松林哨台。
3. 在哨台与时迁查探，开放营后小径、营地，以及茶棚直达小径的捷径。
4. 老藤坡可标记采藤点，一次性取得山藤 3；之后古道派遣每批山藤额外 +1，不追补已有暂存。
5. 可直接攻营，也可在小径花山藤 2 固定警铃，解锁后路潜入。拆铃只付一次材料，以后仍可在两条路线间选择。
6. 战胜头目后，取回货物，收取一次性谢礼：粗布 4、皮革 2。商队回到茶棚，出现补给商店入口。
7. 回茶棚邀请时迁。已有时迁时保留原培养，不重复发人物或信物。

新营地需要同难度古道战绩 1 次；地图内还需查探哨位。没有套用前三个地区的五次入口条件。旧地区条件与招贤概率不变。

## 重复挑战与战斗选择

新增青石古道、藏货营地两个特殊副本，各有寻常、险境、深处三档。好汉小队出战，不扣体力、粮草或士兵；手动用药照常消耗。战败、撤退不发掉落，不推进人物事件。

古道掉落表含 13 项，营地含 10 项，覆盖山藤、皮革、布匹、加工材料、药品与轻装装备。普通路线逐项独立判定，也可能没有掉落；掉落表展示实际概率。既有副本掉落表未改动。

- 哨台使用侧道伏兵路线：多一名骑匪，全敌气血与速度 +10%；胜利额外碎铁 2。
- 正面攻营：头目蓄势 3 秒后号令齐射。第二位传令哨还活着时攻击全队；先击倒传令哨后变为前排单体攻击，也可直接打断头目。
- 后路潜入：需先拆铃，头目的蓄势攻击始终只打前排一人；胜利额外山藤 1。随机掉落表与正面路线相同。

首领提示会随警铃、传令哨状态变化，并提供集火传令哨入口。出征预览取消不扣资源；战后自动结算保存，玩家选择继续探索或查看详情。

## 派遣与回寨用途

通关古道任一难度即可派遣，原来通过五段游历解锁的存档也继续有效。固定地图不会冒充一次完整游历，不发游历路契、周招贤令或游历战法。

古道与五段游历共同累计本地区采集进度：三次通关后山藤每批 +1，通关第二档后主要原料每批 +1；老藤坡手动标记另加山藤 1。离线仍最多积存八小时。旧档已经累计的三次进度不回退。

完成时迁委托并建成客舍后：

- 古道派遣每批皮革额外 +1。
- 斥候短褐配方的山藤由 6 减至 5。其余为粗布 4、皮革 2、碎银 100，每日最多 2 件；矿砂炉已建时碎银为 80。
- 地图、客舍和领取后的材料用途页面均有配方入口。

顺路寻访仍是每四小时取得时迁信物 1，最多暂存 2；不自动招募、不改变抽取概率。

## 存档与发布

增加可选的 exploration.forest 记录，保存地点、事件和待结算战斗的进攻方式。旧存档不要求具有该字段。校验战斗与地点、潜入与拆铃、邀请与货物回收的对应关系，拒绝重复领取、库存溢出和越过事件前置。

Worker 新增 forestExploration:1 能力。完整新版本还需此前的 ruinsExploration:1。旧 Worker 会在上传前得到更新提示；地图内外的新古道副本记录都受此检查。云端禁止普通上传丢失已保存的区域地点与事件。未新增数据库表，不需要执行 SQL。

准备发布时先部署当前 Worker，再推送 GitHub 前端。Android 源码目标同步为 0.71.0 / versionCode 43；本轮未重打包。
