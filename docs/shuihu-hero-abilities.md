# 0.46.0 人物本领完整清单

覆盖当前全部 172 人（108 将、4 名外传人物、60 名江湖散人）。每人有具名本领；新增 160 人使用 29 种共享机制，原有 12 人保留原数值。人物招式、专属兵种与本领共同生效，并非每人新增一套独立战斗引擎。

新开正式战斗使用规则版本 3；旧版本在途战斗按原规则结算。需要治疗、打断的本领须有实际可用招式；有效治疗包括援护，不包括药品。
