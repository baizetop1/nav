# 0.69.0：区域探索、派遣与回寨营建

整理日期：2026-10-10。本版包含 0.68.0 之后这一批本地开发。未完成事项统一维护在 [开发清单](shuihu-roadmap.md)。

## 在哪里玩

- **江湖 → 区域探索**：选择旧矿洞或芦苇泽。地点与道路提前可见，当前位置和事件保存。
- **寨子 → 探索营建**：查看江湖故人、矿砂炉、配药间和客舍。
- **寨子 → 挂机安排**：寨中生产、已通关地区派遣、领取后的材料用途。
- **寨子 → 山寨战役**：选择粮路的护送、侦察或强攻办法，经营作为冒险支援。

## 完整的两片区域

旧矿洞：清理矿道，救出矿工老杜，勘察深层矿脉。帮汤隆修炉、取回工具后邀请入寨；矿头退去后，货郎回到矿口。矿脉改善磁铁砂采集，客舍安置老杜后增加碎铁。

芦苇泽：浅水苇道与毒水湾风险不同。毒水湾开场全队中毒、多一条毒蛇，胜利额外获得药草 3；其他掉落仍按原概率。与安道全救治药农，可选交解毒丹或药草、粗布；恢复药圃后增加泽兰采集。夺回沉船药箱后邀请安道全，配合配药间改善药草采集与金疮膏配方。

人物、藏物等一次性奖励不能重复领取。已有汤隆或安道全的存档能完成事件，不重复发人物或信物。区域战斗不耗体力、粮草，不派士兵；战斗用药照常消耗。

其余四个派遣地区已有基础副本／游历与地区配方，完整区域地图、人物事件和持续变化仍待逐区补齐。

## 派遣与营建

六地区均有独有材料和可用配方。备用好汉每半小时采集一批，最多暂存八小时；主动通关与发现改善后续收益，不追补原暂存。顺路寻访每四小时一枚地区人物信物，最多暂存两枚。领取后可直接查看能制作什么、能培养谁。

地区扩建包括矿砂炉、配药间和客舍，消耗不同地区的材料并提供加工或采集收益。具体材料、收益和共享次数见 [生产说明](shuihu-production.md)。

## 指引与战斗

补充开局、主线与演武操作指引；战场总览展示双方阵容、血量、状态和集火目标。普通战斗结束后自动结算并保存，弹出“继续／查看战报”，不再要求翻页领取。保存失败和标签页冲突仍会提示，按钮不会再次发放奖励。

区域地图在 320 像素小屏可同时显示六个地点和当前目标。修复“查看材料用途”没有真正进入用途页、地区制作后跳回探索页的问题。

## 存档与发布

存档主体版本仍为 2。新增的可选记录包括 grainRoad、idleDispatch、gathering、exploration；芦苇泽位于 exploration.marsh。旧档首次参与相应玩法时建立记录。Worker 保留这些字段，并阻止旧客户端覆盖掉已完成区域事件与发现。

发布顺序：

1. 通过本地游戏自检、构建与相关浏览器验证。
2. 部署 Worker：npx wrangler deploy --config cloud/shuihu/wrangler.json。
3. 核对 /v1/game-version 的 release 为 0.69.0；grainRoad、idleDispatch、regionalGathering、regionExploration、marshExploration 均为 1。
4. 提交并推送 GitHub main，等待 Pages 工作流发布，核对线上配置及新脚本。

**无需执行新增 D1 迁移，也无需重跑 0002_verified_ranking.sql。** 本次部署不修改玩家存档或数据库表。

Android 源码版本同步为 0.69.0 / versionCode 41，本次未生成新 APK。旧 0.68.0 安装包的内置资源不会随网页更新，重打包与真机验证已列入待办。
