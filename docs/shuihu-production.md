# 白泽水浒 0.19.0：生产收取与工坊订单

## 分开收取和加工

旧版“收取产出与加工”会收取原料并立即消耗木材、碎铁冶炼，可能用掉玩家准备升级建筑或练兵的材料。现在寨子 → 山寨生产提供两项独立操作：

- 预览收取产出：仅收取农田、伐木场及补给畅通据点的物资，不扣木材、碎铁，不改变工坊待加工额度。
- 工坊订单：选择 1、5、10 批或全部可加工数量。每批消耗木材 2、碎铁 2，产精铁 1，不耗碎银和体力；需预览并确认。

可加工数量取工坊额度、两类原料能支持的数量和精铁库存余量的最小值。选择数量过多时，预览先缩减到实际可加工数量，显示原料、成品和额度的前后变化。确认再次检查条件；取消不修改存档、不扣料。未使用额度保留。

库存上限仍为每项 10,000,000；同种物资来自多个产地时合并计算剩余空间，装不下的物资保留在对应产地。告急据点的暂存物资保持锁定，解围后才能收取。

## 预览时钟

生产预览使用只读的当前时刻进度副本，计入已完成的新批次；不提前写盘或入库。预览后额度或库存发生变化时，确认拒绝旧方案并提示重新预览，避免使用过期数量。演武传习预览同步使用当前时刻副本，避免跨日时反复引用昨日次数。

## 存档和发布

继续沿用既有生产库存、工坊 bank 和角色进度，没有新增存档字段或数据库表，无需数据库迁移。已有 0.18.0 未提交改动保留，当前原项目版本为 0.19.0。旧客户端仍保留旧版收取逻辑，多设备应刷新到当前页面版本。本轮没有推送 GitHub、部署云端或修改生产云档。
