# 0.34.1 手机出征与结算弹窗

- 出征准备独立为概览、配置、敌情三个页签。概览展示实际消耗、出发后剩余资源、随军人数、三名好汉和敌方名称；阵容预设、军令和兵力在配置页，兵种克制、战场机制、留守影响和兵损预算在敌情页。
- 确认出征和取消固定在弹窗底部。修改方案仍使用原出征校验：预览不扣资源，取消保留原配置，确认时重新核对变化。
- 结算奖励改为“名称 + 数量”的紧凑单行列表。每页最多八项，超出后翻页，所有奖励均已在结算时发放，翻页不再次结算。
- 随军、归营、伤兵、阵亡压缩为四列；完整贡献和调整建议通过战斗复盘页签查看。“收好，继续”固定底部。
- 弹窗有独立的手机字号、留白与按钮样式，解决旧紧凑样式只作用于正文、未覆盖 body 下结算弹窗的问题。

## 验证与兼容

`npm run test:shuihu-dialog-pages` 覆盖预览只读、操作控件保留、校验错误可见、奖励完整分页与伤亡显示；原有出征和结算规则不变。

浏览器隔离存档在 360×640、390×844、412×780、844×390 和桌面验证。三人百兵出征概览、八项结算在竖屏首屏完整显示；横屏和展开的详细敌情可滚动，底部确认始终可用。验证取消不改兵力、更新预览、19 项奖励分页无遗漏及真实战斗结算与复盘入口。

纯前端更新，不需要数据库迁移或 Worker 更新。Android versionCode 35 / versionName 0.34.1，使用原签名覆盖安装保留 App 数据；不要先卸载。Android 真机仍需用户安装后体验。
