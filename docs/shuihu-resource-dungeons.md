# 0.53.0 基础资源副本

入口：寨子总览「资源副本」，或「更多 → 历练 → 资源副本」。行囊「养成材料」可分别跳到四种资源；钱袋旁「获取碎银」可直达银两本，药草详情可直达药草本。

| 副本 | 资源 | 1 / 2 / 3 阶每次胜利所得 | 存放位置 |
| --- | --- | --- | --- |
| 商路护镖 | 碎银 | 300 / 700 / 1400 | 钱袋 |
| 粮车接应 | 粮草 | 60 / 140 / 280 | 寨库 |
| 林场清匪 | 木材 | 40 / 95 / 190 | 寨库 |
| 药圃驱寇 | 药草 | 6 / 14 / 28 | 行囊 |

每日全部开放。每种资源独立 3 次，三个难度共用次数，北京时间零点重置。每次消耗体力 10，不耗粮、不带兵；失败或撤退不退体力和次数，不发资源。奖励固定，不掺招贤令、稀有材料或固定经验。

难度门槛：聚义厅 1 / 2 / 3 级，出阵队伍至少一位好汉 1 / 11 / 21 级。低难度供前期补缺，高难度提高每点体力所得。保留好汉本领、藏品、军令和组合效果，原有带兵方式及计划兵力不变，不消耗预备的行军烟幕。

同一难度两次在 60 秒内全员存活且未用药通关，可解锁扫荡。扫荡执行真实战斗计算，确认前展示消耗和收益；取消不扣资源。库存不能完整装下固定奖励时，入场前拦截，不浪费体力或次数。粮草、木材进寨库，与行囊中用于加工的同名原料分开存放。

## 云存档及上线

本机存档自动兼容，不改数据库表，无须执行 SQL。

先部署此版本 Worker，再发布前端。含新资源本进度的上传会检查 /v1/game-version 的 resourceDungeons === 1，旧 Worker 不会收到覆盖请求。新 Worker 也会拒绝普通上传回退资源次数或熟练记录；下一日正常清零和专用历史回滚仍可用。

在 Git Bash 的项目目录中逐行执行：

```bash
npm ci
npm run test:game
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
git status
git add .
git commit -m "新增基础资源副本与获取入口"
git pull --rebase origin main
git push origin main
```

提交前查看 git status，确认包含本次新增文件。rebase 如发生冲突，解决后 git add 对应文件、git rebase --continue，再推送。不要强制推送。GitHub 提交不等于 Worker 部署，也不会更新手机内置 APK。
