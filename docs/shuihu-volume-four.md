# 白泽水浒 0.22.0：第四卷《三山聚义》

第四卷已开放，承接第三卷《梁山初聚》。二龙山、桃花山、白虎山可自由选择结盟顺序，每寨两种合作方式，选出的三项支援会实际影响最后的联合守寨战。本文记录 0.22.0 的第四卷实现；后续 0.23.0 已开放第五卷《三打祝家庄》，见 [第五卷说明](shuihu-volume-five.md)。

## 入口和地图

完成第三卷后，从江湖地图中的水泊盟亭进入三山驿路。寨子与梁山志提供第四卷目标板，点击可定位地图；查看不会自动移动、领取或消耗物资。

九处地点从一开始即可在全图查看道路与门槛：三山驿路、二龙山客舍、二龙山险道、桃花山修械棚、桃花山校场、白虎山议棚、白虎山粮径、山外递信亭、三山联合营。

三个山寨主地点均可先去，不要求招齐指定好汉。三寨结盟且聚义厅达到 3 级，才可进入联合营。招贤、打造、训练和生产继续使用原来的直接入口；地图提供额外事务和支援。

## 合作方式

| 山寨 | 物资或情报路线 | 战斗路线 |
| --- | --- | --- |
| 二龙山 | 交药草 6、金创药 2，获得医援：我方最大气血 +12% | 进入险道解围，胜后回客舍确认，获得护阵：我方防御 +12% |
| 桃花山 | 交精铁 6、粗布 4，获得器械：我方攻击 +10% | 前往校场切磋，胜后回修械棚确认，获得奇袭：敌方防御降低 12% |
| 白虎山 | 先改为英雄独行到递信亭获取传书，再交碎银 200，获得先手：我方初始怒气 +20，上限 100 | 前往粮径护送，胜后回议棚确认，获得辎重：我方最大气血 +8% |

白虎山只要求获取传书时独行，获取后可恢复带兵；护粮路线不需要传书。

每寨只能确定一种合作方式。材料不足会拒绝整次操作，不会扣掉部分材料。交付完成或战胜后回议事处确认即结盟，随后不能反复切换或领取。尚未结盟时，可从交战地点返回商议改选路线，撤退或失败消耗的体力、粮草不退还。

结盟分别结识鲁智深／杨志、李忠／周通、孔明／孔亮并给予少量信物。结识不等于自动入队；已有英雄的等级、品质、经验和出阵配置保持原样。

## 出征和联合支援

三场结盟战要求聚义厅至少 2 级、队中至少一人 18 级，每场体力 10。联合守寨要求聚义厅至少 3 级、队中至少一人 22 级，体力 16。各战粮耗为 `8 + 向上取整(实际随行人数 / 2)`，独行消耗 8 粮。

使用真实出阵英雄与部队，支持军令、专属兵种、招式、首领蓄势、独行及带兵。出征准备显示实际属性和费用，可调整阵容；取消不扣费。等级是入场门槛，不保证任意阵容必胜；连续出征后可先治疗伤兵、补员，独行队需要更充分的培养。

三项结盟支援只在第四卷联合守寨生成战局时生效，预览和战斗日志均展示来源及效果，不影响日常本、周本或其他战役。气血支援依次相乘，每次四舍五入到整数，开战气血等于新的最大值。战中存档已经包含加成，刷新继续不会再次叠加。

联合战胜利后，在当地确认战果并立约，完成第四卷；卷终另得招贤令 3、登仙印 2。差事页提供四份对应任务奖励。确认完成后不可重复领取。

## 发布与存档

新增内容使用已有地图、剧情步骤、flags 和战斗快照字段，存档版本仍为 2，旧进度无需重置。**无需新增数据库表，也无需执行迁移 SQL。**

**云存档 Worker 需要更新到本版。** 上传第四卷进度前，客户端检查 `/v1/game-version` 的 `chapters >= 4`；旧服务会收到前端的升级提示，不会接收无法识别的新进度。

建议先部署 Worker，再推送 GitHub 发布前端：

```bash
npx wrangler deploy --config cloud/shuihu/wrangler.json
```

本轮只修改本地项目并验证，尚未推送 GitHub、部署云服务或操作线上存档。
