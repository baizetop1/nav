# 全站外观

导航首页、博客工作台、管理后台与 Tech OS 共用一套外观设置。点击工具栏中的调色板按钮（“外观设置”）即可切换，选择后立即生效。

## 四套风格

| 名称 | 标识 | 风格 |
| --- | --- | --- |
| 山水清境 | `landscape` | 延续青绿山水与清静留白，默认风格。 |
| 雾蓝晨光 | `mist` | 雾蓝色、轻柔光感，适合阅读与整理。 |
| 暖纸书房 | `paper` | 温暖纸色与纸张纹理，适合书写。 |
| 石墨极简 | `graphite` | 克制的石墨色与简洁背景。 |

每套风格都有明亮与深色版本，可以在外观设置的“明暗外观”中切换。原来的明暗按钮与命令仍然有效，与外观主题独立；切换外观不会改变明暗偏好。

## 固定与每日模式

- **固定主题**：一直使用选中的风格，刷新和切换工作台后保持一致。
- **每日换一套**：根据本机日历日期，在四套主题中确定性轮换。同一天重新打开会得到同一套风格。
- 开启每日模式时立即使用当天主题；之后仅在重新打开或刷新页面时重新计算。午夜、路由切换、重新聚焦窗口不会突然改变正在编辑的页面。
- 点选任意主题卡片会改为固定主题，即使点选的是每日模式当前使用的那一套。

日常、工作、学习、休闲场景仍然独立。工作场景关闭背景装饰层，保留主题底色与内容配色；学习场景降低装饰干扰。外观不会修改导航、便签、博客、Tech OS 数据或独立游戏页面。

## 本机保存与恢复

新增加的主题配色与每日轮换偏好只保存到当前浏览器的 `localStorage`，不加入加密同步、备份或 GitHub 发布：

```json
{
  "version": 1,
  "mode": "fixed",
  "themeId": "landscape"
}
```

存储键为 `baize_appearance_v1`；明暗继续使用原来的 `theme` 键及其既有保存、同步机制，不改变原来的同步范围。没有外观记录时使用“山水清境 / 固定主题”。无法识别的记录会临时回退默认主题，并在设置中提示，不会自动覆盖原文；主动选择后才保存新记录。

浏览器禁用存储或空间不足时，当前选择仍在本次页面会话中生效，设置面板显示失败原因与“重试保存”。刷新可能恢复为上次成功保存的选择，因此应先解除存储限制并重试。

## 键盘与布局

设置面板使用具名对话框与原生单选按钮。打开后焦点进入面板，Tab / Shift+Tab 保持在面板内，方向键可切换同组单选项；Esc 或关闭按钮关闭并返回原入口。背景内容在对话框打开期间不可交互。面板支持窄屏与内部滚动。

## 实现边界

- `AppearanceProvider` 位于应用根部，跨工作台路由保留本次会话的外观状态。
- `html[data-appearance]` 标识当前主题；`html.dark` 仍标识明暗。
- 主题变量统一提供底色、装饰、文字、边框、面板及按钮配色。共享 `AppearanceBackdrop` 只使用本地资源与静态 CSS，不请求外部壁纸、不启动轮播计时器。
- `html[data-appearance-scene]` 让工作、学习等场景独立控制装饰强度。
- 独立游戏入口不引入该外观控制，也不修改其存档。

## 验证

纯函数自检：

```powershell
npm run test:appearance
```

先构建并启动本地预览（默认 `http://127.0.0.1:5189/nav/`），再运行浏览器回归：

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 5189
# 在另一个终端执行；未在项目安装 Playwright 时指定已有依赖目录。
$env:BAIZE_PLAYWRIGHT_PATH = 'C:/path/to/node_modules/playwright'
npm run check:appearance
```

可以用 `BAIZE_APP_URL` 覆盖预览地址、用 `BAIZE_BROWSER_CHANNEL` 覆盖浏览器通道（默认 `msedge`）。

浏览器脚本覆盖 1440px 桌面和 390px 手机宽度，检查四主题在四个工作区中的一致性、真实主按钮文字对比度（至少 4.5:1）、明暗独立、刷新恢复、每日日期/会话规则、工作场景装饰静默、对话框焦点与 Esc、存储配额失败及重试、无效记录保护与主动恢复、横向溢出和页面异常。

测试阻断全部外部请求与所有网络写入，不使用真实 GitHub 凭据。截图和测量报告输出到已忽略的 `artifacts/appearance/`，包括四主题首页、代表性工作台、设置、工作场景和存储错误提示。
