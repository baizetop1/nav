# 白泽水浒 0.15.0：批量养成与采买

## 操作入口

- 好汉详情：经验丹提供五次、十次预览。
- 人物往事与招式：专属招式书提供五次、十次抄录预览。
- 专属坐骑：已领骑后可预览批量喂养。
- 行囊 → 随时采买：选择物品，再预览五份或十份采购。

预览显示实际可办数量、总消耗和结果，取消不修改存档。数量受现有资源、人物满级、亲密 100、库存上限、招贤令每日限购三张约束。最后一颗经验丹或一份草料仍按整份使用，不退回溢出部分；达到上限后不再使用下一份。

确认后按预览数量一次办理，保留原有单次操作的价格和效果。若确认时材料不足，或结果与预览不同，整批拒绝，不先扣掉一部分。战斗、计策、际遇中不能办理。每批仅增加一条汇总日志，领取与成长结果使用已有收获弹窗。

本轮也补齐普通单次招式升级、坐骑喂养及升阶的收获弹窗。招贤抽取和随机强化不纳入批量养成。

## 存档与验证

无新增存档字段、数据库迁移或云端能力要求；沿用现有存档格式。若旧版 0.14.0 云端服务仍未升级，仍按原升级说明处理。此轮不自动推送或部署。

测试覆盖四类批量操作与逐次操作的一致性、不可变预览、上限减量、限购、原子失败、过期预览、库存边界、交战禁用与文件往返。完整自检、生产构建通过；隔离浏览器在手机和桌面尺寸下验证取消、确认、满级停药、满亲密停止、限购、弹窗和重载，并移除旧手机可能缺失的三个接口复测。
