# 白泽水浒 0.81.0 · 物品来源与目标追踪

玩家查缺料时，原先会遇到几套不同的来源说明：部分不可购买的材料被指向采买，药品配方会跳到材料分类，旧装备目标还保留五次通关提示。本轮合并来源入口，并接回旧养成目标。

## 入口与操作

- 更多 → 其他 → 物品来源，或行囊 → 物品来源。也可从物品详情、打造缺料、人物信物与目标中的材料进入。
- 可搜索 675 种道具、41 种装备和碎银、寨仓木材、寨仓粮草，共 719 项。未持有的物品也能查。
- 每页选一件物品、一处来源；“所需材料”直接查缺料，返回后恢复原配方和选择。“用途”连接相关配方。
- 固定奖励、概率掉落、加工、购买、派遣、一次谢礼分别标示。随机掉落不承诺刷取次数；招贤概率没有调整。
- 选择来源只打开入口或预览。购买仍须点击购买，出征仍走原准备与确认流程。

## 目标

材料可指定备齐数量；装备可追踪一件。原升品、练兵、打造、打法、人物任务、阶段与 17 项地区目标继续保留。查看其他来源不会换目标，必须明确点击“改为追踪此物”。

首页统一显示当前目标和下一步。材料目标按目前持有量计算；材料花掉后会重新出现缺口。营建木材与行囊木材不混算。

## 来源条件

- 特殊副本各难度的概率和数量读取实际结算表；支路固定掉落读取同一支路配置与解锁检查。
- 材料日历显示开放日、每日次数、体力与粮耗；周本显示本期首通层数。普通历练、坐骑契、独立装备搜获按原规则显示。
- 普通配方和地区加工保留设施、学习、材料与共同日额度；重访和跨地共事加工显示实际条件。
- 六地重访、李云入寨、药船谢礼以及章节和差事奖励标记已领状态；招贤信物区分外传与普通池。主线和随机际遇保留各自剧情入口，不伪装成保证掉落。
- 派遣显示空闲好汉、地区通关、实际批次产量与顺路寻访规则。

## 存档与发布

新增目标仅使用 development.goal 的 kind=stock、id、amount，限定正整数数量；原目标结构不变。文件与 Worker 使用同一校验，数量不会在上传中丢失。上传这类目标要求云服务返回 sourceTracking:1；旧 Worker 时先提示升级，本机进度保留。无需 D1 迁移。

本地源码版本 0.81.0；Android 源码版本 0.81.0 / 53，未重打包。发布顺序仍为更新 Worker，再推送 GitHub 前端；本轮未进行发布。
