# 0.61.0 郓城与景阳冈场景

## 本次改动

“江湖 → 剧情行路”在郓城至景阳冈的 11 个地点默认显示场景页。新增郓城街道、酒肆、景阳冈三张插画，按地点复用；地图选中这些地点时也可预览并放大。其他地点保留原有页面，未宣称十二卷均已插画化。

场景分“眼前”“人物传闻”“附近道路”。眼前保留实际剧情对白和选择；传闻调用原有结识、向导与消息操作；道路显示相邻地点及锁定条件。主线指引仍按存档中缺少的条件安排路线，不会自动代办剧情。可随时切到“查看全文”，再点“走进此地”返回。

查到爪印、追踪成功和打虎完成后，环境描述随进度变化。武松仍是本战临时助阵，胜利不会直接入寨。查脚印、追踪、真实交战、战后对话和奖励领取均沿用原规则；没有改抽取概率、掉落或战斗数值。

小屏使用紧凑横幅、对白和操作，次要信息放到标签页；大图单独打开。主线指引与地点操作会清理旧标签选择，避免回到不相关的内容页。

## 存档与发布

场景完全由现有地点、主线旗标、世界时间和人物状态推导；标签选择只存在于当前界面。存档格式仍为 version 2，无新增数据库表或迁移。本次 0.61.0 单独不需要更新 Worker；如果此前 0.59.0 的服务端更新尚未部署，仍应按该版本说明部署一次。

静态网站更新需提交新增脚本、样式和 `public/game/art/scenes` 图片。图片共约 985 KiB，按所在地点加载，采用本地 WebP。素材来源与生成提示词见 `public/game/art/scenes/README.md`。
