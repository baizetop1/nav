# 白泽水浒 · 当前进度与后续开发

更新时间：2026-10-10。当前代码版本：**0.69.0**。

本文件持续维护当前进度；本次内容见 [0.69.0 更新说明](shuihu-v069.md)，具体材料、存档与发布规则见 [探索与生产说明](shuihu-production.md)。原 0.20.0 路线图已归档为 [历史记录](shuihu-v020.md)。

## 已确定的方向

主线把玩家带进江湖。长期游玩以探索、好汉收集和小队战斗为主；山寨养成、粮路战役提供支援。挂机只做寨中生产和已通关地区采集，不离线代打首领、不自动消耗主力兵队。

招贤概率与原特殊副本随机掉落表保持现有配置。新增确定收益要写明条件、消耗与上限；人物、藏物等一次性奖励必须防止重复领取。手机优先显示当前目标与关键操作，长内容通过独立页面或分页查看。
