# 白泽水浒 0.90.4 · 物品图标与副本小图

日期：2026-10-17。

物品增加同画风的透明物件图标，覆盖药品、粮食、矿材、木料、布皮、书卷、令牌和装备。36种物件图对应847项物品与41项装备，按物件类别共用；个人核心与信物使用对应好汉人像并区分“炼／信”小徽。烟幕包使用袋装轮廓，守炉重锤复用既有锤形线图。名称、数量、品质和按钮保留，不依赖图片传达操作信息。

图标已接入行囊列表与详情、来源查询、打造、装备比较、地区配方、资源奖励、特殊副本掉落与战后收获。下拉选项仍保持纯文字。

副本标题旁加入小幅场景图，普通手机为64×36，窄屏或短屏为56×32；复用现有33张插画覆盖80个场景条目（含42处战役回顾）。资源、材料日常、周本、精英、剧情、特殊与人物专属挑战均有对应场景。当地主页与升品试炼入口同步补图；独立人物篇章保留现有场景插画。矿洞及炉底暂复用冶铁棚，地宫复用荒祠外景；不把这些复用插画标作新绘内室。

新资产：public/game/assets/art/items-sheet.png，1254×1254 RGBA，36格。生成来源及完整提示词见[素材记录](art/item-icons.md)。
