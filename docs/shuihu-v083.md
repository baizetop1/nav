更新时间：2026-10-14。发布内容以本说明及当前代码为准；六地探索、重访、共事与寨中生活继续保留。

## 可以从哪里检查

- 更多 → 寨务 → 招贤：当期招募、专属招贤、招贤补给。
- 更多 → 好汉 → 名册：正册、外传、散人；手机一页八人，桌面一页十二人。

- 更多 → 历练 → 特殊副本：地点、难度下拉切换；挑战、掉落、战绩分开查看。核心材料位于掉落页的“升品”分类。
- 更多 → 其他 → 差事：选择今日差事，可直接进入对应副本、招贤、整备或物品来源。

## 活动招贤

采用北京时间每月三期：1—10 日、11—20 日、21 日至月末。每期 17 位：正册三位、外传两位，一至三星散人各四位。页内可看当月三期名单。正册一年十二个月共轮换 108 位；已有专属令和缘分保留，等待该人物再到访。

首次抽中直接入寨，无须相识。名册删除正册和散人的低价银两购买；地图事件完成后的相邀、外传委托信物邀请仍可进行。重复人物转为本人信物三枚、功勋十五；原人物等级、经验、招式、装备和品阶保留。

普通招贤各档概率为五星 1%、四星 6%、三星 23%、二星 45%、一星 25%。同档当期人物均分概率，20／50／100 次星级保底沿用；单抽、十连和换期共用进度。专属招贤目标 25%、其他当期正册 5%、当期其他人物 70%；连续四次未得目标，第五次必得。招贤补给的荐书与积分只能兑换当前名单，旧积分和荐书保留。

换期前的按钮携带当期标识；跨期后先拒绝旧名单操作，提醒重新查看，不扣令、积分或保底，不改变随机种子。查看日历与概率不推进抽取。

## 人物体系与品阶

正册使用五星招募档，外传使用四星档；散人保持原一至三星资质。人物体系与凡／灵／仙成长品阶分开。

基础养成属性采用正册 1.20、外传 0.90、散人 0.65 的体系系数，速度不按该系数扩大。正册另按职业保证基础与成长下限，使同职业、同等级、同品阶、相同装备时有明确体系差距。旧资质字段不改写，已投入的装备、招式和品阶继续生效。临时剧情人物保留教习数值。

凡品为方印，灵品为六角玉印，仙品为金轮；图形、文字和颜色共同区分。已入寨人物显示彩色头像与“已入寨”，未获得人物显示灰色头像与“未获得”。

172 位人物各有一项独立核心材料，凡升灵需三份，灵升仙需八份；银两、灵蕴、登仙印等原通用辅料与等级、聚义厅条件保留。已经升品的旧人物不会被降品或追补费用。

核心材料散落在六地普通／首领特殊副本，以及对应的剧情副本。特殊副本三档核心掉落率分别为 40%／55%／70%，剧情副本为 50%；命中后有 25% 概率获得两份，其余获得一份。该掉落单独结算，不替换原装备和材料的随机掉落表。

追踪某人升品或追踪该核心材料后，在对应产地定向掉落；无须把待培养人物放入出阵队伍。不追踪时优先从对应地区已入寨人物的核心材料中抽取。来源页显示实际产地、概率和用途；单纯预览不会发奖或推进随机种子。

## 固定难度函数

关卡按类型、固定等级、品阶、首领与该档修正计算，玩家升级不会使旧关卡同步变强。令 x = 等级 − 1（等级限定在 1—40）：

| 属性 | 等级曲线 |
| --- | --- |
| 气血 | 1 + 0.12x + 0.003x² |
| 攻击 | 1 + 0.065x + 0.0012x² |
| 防御 | 1 + 0.04x + 0.0005x² |
| 谋略 | 1 + 0.075x + 0.0012x² |
| 速度 | 1 + min(0.18, 0.0045x) |

以上再乘资源、主线、探索、周本、挑战、寨务、据点或游历各自的类型系数，以及关卡品阶和首领修正。侦察面板读取同一函数；多波增援沿用该战局规则。主线往事的温习保留 0.65 倍、实战保留 1 倍差异。

专项试炼五层固定为 15／20／25／30／35 级，逐层递增且不超过角色上限；凡品组推荐凡品队伍。商盟急托保留较同地区普通战斗 30% 的增强。

资源副本偏向稳定补给；高阶探索、周本和挑战要求相应养成与敌情应对。第一档探索单独校准正常新档，保留第二、第三档挑战。三种实际开局种子从打虎、两次活动招募、培养与剿匪，走通矿洞救人、首领、汤隆邀请、夺车重访与长枪打造：六战合计约 156—199 秒战斗内计时，使用原有药品三至四份。实际阅读与决策耗时另需真人试玩。

深层首领的测试包含等级不足失败、默认集火失败、优先治疗敌人后成功；高阶周本包含未整备失败与完整养成成功。升品试炼用下一品阶之前的队伍验证，避免要先升品才能取得升品辅料。
