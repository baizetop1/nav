# 白泽水浒 0.51.0：破连环马

本文记录 0.51.0 开放第七卷时的交付。第八至十二卷现已在 0.52.0 实现，当前升级步骤见 [0.52 更新说明](shuihu-v052.md)，完整内容见 [主线实施记录](shuihu-mainline-plan.md)。

## 从哪里继续

完成第六卷《高唐救援》后，寨子首页优先显示主线。点击“继续主线”前往泊东营地，接上急报；也可从高唐城南接应点前往。

七个地点、八段剧情：泊东急报 → 土岗观阵 → 渡口试锋 → 铁棚议策 → 钩断连环 → 双鞭中军 → 解甲留营。北路截援是可选战斗。主线不要求抽到徐宁、汤隆或呼延灼，已培养的同名人物不会被重置。

三场必经战斗与一场可选战斗均要求聚义厅 4 级；渡口试锋要求队中一人 35 级，截援与破阵 36 级，中军 38 级。体力分别为 12、12、14、18；粮草沿用实际出征规则。可带兵或独行，失败、撤退仍扣本次消耗，带兵会结算真实伤亡。门槛不是保胜条件，需根据装备、招式与兵力备战。

## 破阵选择

| 准备 | 一次费用 | 破阵与决战的效果 |
| --- | --- | --- |
| 钩镰 | 精铁 8、碎银 120 | 敌军防御降低 25% |
| 壕沟 | 木材 8、粗布 8、碎银 120 | 敌军攻击降低 20%、速度降低 15% |

选择前显示费用和效果，并要求确认。取消不扣资源；确认后本卷不能更换。无需特定人物入队。完成北路截援后，决战少一队弓手；击退中军后不能再发起截援，已经获胜的截援仍可返回确认战果。

## 引导与奖励

战斗胜利后，“继续主线”先回到本战剧情确认战果，再指向下一处；可选截援也按这套流程。切换页面、回营、刷新或导入存档后，目标由真实进度恢复。等级、聚义厅、体力、粮草、队伍和兵力不足时，可前往对应页面处理。

卷终一次发放招贤令 4、登仙印 2、灵蕴 8；原有章节招贤补给另可领招贤令 2，因此本卷合计 6 枚。解甲留营给呼延灼、徐宁、汤隆信物各 3，其余节点给武学残页与招贤碎片。已完成节点不能重复领取，抽取概率保持原值。

在 0.51.0 中，结卷提示第八卷尚未开放；0.52.0 已改为直接接续曾头疑云。梁山志里的后续篇章仅供查看设计，没有虚假的地图或出征按钮。手机沿用分页，主线按钮放在寨子首页，长剧情与结算无需整页下拉。

## 存档与更新顺序

旧档直接兼容，沿用剧情标记、故事记录与战报，不新增数据库表。云端需要更新 Worker；旧 Worker 不支持七卷时，上传前提示升级，本机进度保留，不发送不兼容存档。

普通上传不能倒退第七卷进度或改掉已选战法；原有明确操作的历史回滚仍可使用。

在项目根目录依次执行：

~~~bash
npm run test:game
npm run build
npx wrangler deploy --config cloud/shuihu/wrangler.json
~~~

然后按现有 GitHub / Pages 流程提交并发布前端。无须执行数据库 SQL。已有 save 子域名网关配置可继续使用。本轮开发未推送 GitHub，也未部署线上。
