# 白泽水浒 0.27.0 · 经营侧重、材料扫荡与存档比较

## 经营与出征

开办经营拓土后，山寨生产可以选择均衡、粮草优先、木材优先、工坊优先。均衡仍为每处 30 分钟一批；侧重处 20 分钟一批，其余两处 40 分钟一批。每批产出仍由设施、任职、等级和品质决定。

切换先结算旧侧重的已过去时间，只影响之后的生产。已产物资和未满批次的工作进度保留；四分之一毫秒的余量也写入存档，避免频繁刷新丢失生产进度。暂存上限仍为当前每批产量的 16 倍（已经超过新上限的存货保留），离线最多计八小时。工坊增加的是加工额度，仍须实际支付加工原料。

出征准备新增留守变化：列出随队英雄离岗后生产每批产出的变化，以及带走据点守将的影响。出征时暂停个人任职加成，回来恢复；已有物资不扣回。据点仍沿用六小时无有效守备缓冲。

## 每日材料本扫荡

每条材料路线、每个难度分别记录稳定通关。60 秒内胜利、所有出阵英雄存活、全程不用战斗药品，累计两次解锁该难度扫荡。升级前的通关没有这些完整记录，因此不追溯授予熟练度。高难度记录不会替代低难度记录。

扫荡可选一次或本路线今日剩余次数。先用当前阵容、装备、军令、兵力和随机状态实际演算自动战斗，展示总消耗、材料、伤兵和阵亡，确认才保存结果。药品、治疗伤兵、补员不会自动执行；每一场按上一场剩余的在营兵力出征。原有手动或自动技能偏好在结束后保留。

仍与正常挑战共用每路线每日三次，不增加材料倍率。体力每场 10，粮草依每场实际兵力计算。取消、资源不足、当前阵容演算失败均不扣资源；阵容、资源、次数或日期变化后必须重新预览。扫荡不推进现实时间、不补算生产或体力恢复。周本与服务器演武不支持扫荡，排名规则不变。

## 存档与手机界面

每次上传前读取目标云档，再并排显示本机与云端的章节、英雄人数与最高等级、威望、碎银、兵力、粮木、招贤令、经验丹和战斗状态。时间仅供参考，不自动认定较新进度更好。取消不会上传；确认后同时保留本机序列和云端 If-Match 版本检查。

文件导入、云端接续与备份恢复均可比较目标本机位置，切换编号立即更新比较内容。确认只替换所选编号，保留一份有效备份；预览后被另一标签页改过的目标拒绝覆盖。

本机保存时间与最近上传时间分开显示，旧档没有时间记录时显示“未记录”。密钥仍只存在本页内存，不加入导出文件或游戏存档。手机比较窗口使用独立滚动区域，操作按钮固定在内容区之外。

## 兼容和发布顺序

存档外层版本仍为 2，名册版本仍为 5，112 位人物与六卷内容保留。新增可选字段 frontier.focus、station.workRemainder、campaign.mastery。旧档继续读取；未使用新功能不会自动添加侧重或熟练度。

需要更新 Worker 才能上传这些新字段。服务新增 productionFocus: 1、materialSweeps: 1 能力；前端检测不支持时停止上传并提示升级。Worker 拒绝旧页面静默丢弃已有的新字段。

**本次不改数据库表，不需要新增或重复执行迁移 SQL。** 原有 verified_scores 表继续使用。推荐先发布 Worker，再推送前端；本次开发没有执行远程部署或 Git 推送。
