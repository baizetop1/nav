# 0.74.0：探索目标与护粮回程

开发日期：2026-10-11。本地待审查，未推送 GitHub、未部署 Worker、未生成 APK。包含 0.70—0.73 尚未发布的地区内容；线上上次发布仍为 0.69.0。

## 首页与目标

建寨后，首页显示当前地区的下一件事。点击后查看对应地点，再由玩家选择前往；不会替玩家移动、开战或扣材料。低于 5 级且尚无可探索好汉时，提示先用主线或经验丹培养。主线保留独立入口；备战建议、粮路及全部寨务收进展开菜单。

“探索目标”有 15 个选项：

- 邀好汉：汤隆、安道全、乐和、时迁、阮小七、项充。按各地实际委托提示下一步；其他途径已经入寨也算完成。
- 备装备药品：守路长枪、金疮膏、武学残页、斥候短褐、野营药包、稳步束带。按现有库存判断是否备齐，装备含正在穿戴的；不用重复制作。消耗或分解成品后，会重新显示缺口。
- 扩建寨子：矿砂炉、配药间、客舍。显示设施条件、碎银、营建木材及当地材料缺口。

追踪沿用原 development.goal，同一时间一个目标。浏览不会替换原目标，只有点击“改为追踪此目标”才更换；可以取消。旧的升品、练兵、阵容等目标仍保留。

材料清单按当前实际配方计算，包括营建折扣和人物省料。特产可直接去对应派遣，也提供亲自打材料的入口；碎银、营建木材去专门资源本；铁、布、皮革、药草、行囊木材去军需原料采买。行囊木材与营建木材分别计算。各入口只导航，不自动消费。

人物邀请页、地区配方、地区营建也提供追踪按钮。首页、目标详情和地区图读取同一份进度；重开页面可继续。完成后可直接查看好汉、穿戴装备或查看营建。

当前只覆盖上述六位地区人物、六份地区成品和三项营建。所有人物通用的信物数量追踪、全装备掉落追踪整合仍待后续开发；原装备追踪功能继续可用。

## 断崖粮道的后续事件

项充委托完成后，粮道首页出现车夫来信，不要求重新开档：

1. 回粮道歇棚读信，得知后车失散。
2. 到乱石隘查看车辙和脚印，开放“护粮回程”。
3. 在截粮营选择护粮回程，接应后车。也可从特殊副本的截粮营路线列表进入，通关计入同一委托。
4. 回歇棚报平安，收下赤铜砂 4、项充信物 2、强化符 1；每档只领一次。材料满仓时保留待领状态。

护粮回程可重复挑战，沿用特殊副本三档难度与对应前置。地图入口为寻常档。好汉小队出战，体力 0、粮草 0、不带兵，用药正常消耗。

战斗增加一名绕后伏兵，全敌气血 +10%、速度 +5%。头目不举盾，首次在第 6 秒蓄势，三秒后夹击队伍中最后一位仍能战斗的好汉。击倒最末位伏兵或打断头目可阻止夹击，固守对这一招额外减伤 50%。预览、动向提示和集火按钮对应同一机制。

胜利沿用截粮营原随机掉落，另得熟皮 1/2/3（按难度）；失败、撤退不发奖励。一次性车夫谢礼不随重复挑战再发。原招贤概率与各副本随机掉落概率不变。

## 存档与发布

- 旧档按实际进度自然开放后续，无强制重置。
- 新目标写在 development.goal；后续事件新增四个 mountain.flags，现有字段结构不变。
- 本机、文件、Worker 对目标种类、任务先后、战局绑定和一次性奖励标记进行校验；云端拒绝普通上传丢失已经完成的后续事件。
- Worker 新增 explorationGoals:1。只有使用新目标或进入新后续的存档要求这一能力；旧 Worker 在上传前被拦住，本机进度不丢。
- 沿用现有 D1 表，无需执行 SQL 迁移。发布时先更新 Worker，再发布前端。
- Android 源码版本 0.74.0 / versionCode 46。本轮不生成 APK，已安装包不会自动更换内置资源。
