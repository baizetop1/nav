# 白泽水浒 0.29.1 · 江湖页面分区

江湖原先把领地据点、所有地点的地图和当地功能连续排列，当地主线剧情被推到很下方。本次改成四个独立分区，一次仅显示当前分区内容。

| 分区 | 内容 |
| --- | --- |
| 剧情行路（默认） | 当前地点的剧情、选择、交谈与关键事务优先显示；随后是下一处剧情路线、附近去处和当地消息 |
| 江湖地图 | 全部地点、相连道路、路线预览及开放条件 |
| 当地探索 | 探访酬谢、当地副本、寻访、等候；在马厩可查看坐骑相关功能 |
| 领地据点 | 山外据点、经营拓土与山河经营入口 |

每次点击主导航「江湖」默认进入剧情行路。从地图或附近去处抵达新地点后回到剧情分区顶部。「查看此地事务」也直接打开剧情，不再跳到长地图下方。分区按钮固定在内容区顶部，手机和桌面均可随时切换。

进行中的异地往事显示下一处地点，并可打开路线预览。已完成的当地往事收进折叠区。招贤、打造、行囊等原有独立入口保留。

分区切换只改变界面，不移动角色、不消耗资源、不推进剧情、不写入存档。战斗、计策和事件仍优先显示原有操作界面。

## 发布

本次仅调整前端布局和导航，不新增数据库表，也不修改云端接口。发布前端后刷新页面即可。若此前 0.29.0 的云端协作尚未发布，仍需按 shuihu-v029.md 完成该版本的迁移与 Worker 部署。
