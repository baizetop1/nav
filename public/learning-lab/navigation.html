导航实验页

先预测，再操作，再看证据。本页是静态 HTML，不调用外部 API、不注册 Service Worker、不保存输入。

请使用电脑 Chrome / Edge 的开发者工具 → Network，打开 Preserve log（保留日志），选择 Doc / Document。Network 没有新行不等于没有任何浏览器活动；请同时看地址、缓存和历史恢复。

1. 比较导航入口

  • 普通同源链接：?visit=link
  • 改变查询参数：?topic=network&sample=1
  • 只改变 fragment：#section-two

表单内容会进入地址栏、浏览历史，服务端也可能记录查询串；请勿输入密码、Token 或隐私。刷新与前进后退请使用浏览器自己的按钮。

2. 当前 URL（浏览器解析结果）

fragment 可由此页脚本读取，但不包含在 HTTP 请求目标中。页面没有拦截链接/表单，也没有调用 pushState。

3. 辅助观察，不代替 Network 证据


    
navigation.type 只描述当前文档的加载类型，并不能证明“刚才发出了 HTTP 请求”。锚点变化通常沿用当前文档。缓存、连接复用、bfcache 和上级 Service Worker 都可能改变现象。此页不保证 302、304、TCP/TLS 新连接或离线可用。
