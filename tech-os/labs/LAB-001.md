## 目标

观察域名解析结果、记录类型、TTL 和递归服务器，并为 `KNOWLEDGE-001` 提供 L2 前的实验材料。

## 环境

- Windows：`nslookup` 或 `Resolve-DnsName`。
- 可选：`dig`、浏览器网络面板、抓包工具。

## 步骤

1. 查询一个同时存在 A/AAAA 或 CNAME 的域名。
2. 记录所使用的 DNS 服务器、返回记录与 TTL。
3. 重复查询并观察缓存行为。
4. 更换递归 DNS 后比较结果。
